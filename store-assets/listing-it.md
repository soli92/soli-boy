## Descrizione completa (≤4000 caratteri)

Soli-Boy è un emulatore Game Boy e Game Boy Advance che mette la privacy al primo posto:
tutto gira **sul tuo dispositivo**. Le tue ROM, i tuoi salvataggi e i tuoi BIOS non lasciano
mai il dispositivo — nessun upload, nessun account, nessuna telemetria.

Caratteristiche:
• Emulazione GB e GBA via core open source (mGBA / WasmBoy)
• Funziona offline: nessuna connessione richiesta per giocare
• Salvataggi e save-state gestiti localmente, con export/import
• Controlli touch su mobile (D-pad + pulsanti virtuali configurabili)
• Supporto controller Bluetooth (Gamepad API) con nascondimento automatico dei comandi touch
• Feedback aptico opzionale sugli input touch
• Layout responsivo con supporto orientamento e safe-area (notch)
• Temi visivi (chiaro, scuro, 90s-party, cyberpunk)
• Desktop (Windows/macOS/Linux via app dedicata) con aggiornamento automatico
• Accessibilità: conforme WCAG 2.2 AA sui controlli principali

Soli-Boy NON include ROM o BIOS protetti da copyright: usa esclusivamente i file di cui
possiedi i diritti. Un avviso legale in-app lo ricorda.
