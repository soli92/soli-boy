## Short description (≤80 chars)

## Full description (≤4000 chars)

Soli-Boy is a Game Boy and Game Boy Advance emulator built privacy-first: everything runs
**on your device**. Your ROMs, save files and BIOS never leave the device — no upload, no
account, no telemetry.

Features:
• GB and GBA emulation via open-source cores (mGBA / WasmBoy)
• Works offline: no connection required to play
• Local save files and save-states, with export/import
• Touch controls on mobile (configurable virtual D-pad + buttons)
• Bluetooth controller support (Gamepad API) with auto-hide of touch controls
• Optional haptic feedback on touch input
• Responsive layout with orientation and safe-area (notch) support
• Visual themes (light, dark, 90s-party, cyberpunk)
• Desktop app (Windows/macOS/Linux) with automatic updates
• Accessibility: WCAG 2.2 AA compliant on core controls

Soli-Boy does NOT bundle any copyrighted ROM or BIOS: use only files you own the rights to.
An in-app legal notice reminds you of this.
