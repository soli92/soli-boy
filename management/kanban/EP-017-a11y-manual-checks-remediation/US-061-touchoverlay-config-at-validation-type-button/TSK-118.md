# TSK-118 — Fix type=button su "Salva profilo" in Settings.tsx

## Context

**R-05:** In `Settings.tsx` sezione "Controlli" il `<button>Salva profilo</button>`
a `Settings.tsx:423-428` (`[^src5: packages/app/src/components/Settings/Settings.tsx]`)
manca di `type="button"` esplicito. Gli altri pulsanti del file hanno tutti il tipo
esplicito (verifica confermata: `sb-btn-primary`, `sb-btn`, etc. hanno `type="button"`).

Senza `type="button"`, un bottone dentro un `<form>` farebbe submit. Anche se non c'è
form, è coerenza di codice. Pattern concordato: tutti i `<button>` del progetto devono
avere `type="button"` esplicito.

Dipende da TSK-114 (completamento US-059 — scheduling sprint 13 wave).

## Acceptance Criteria

1. Il `<button>Salva profilo</button>` in `Settings.tsx` (accordion Controlli) ha
   `type="button"` esplicito.
2. Grep su `Settings.tsx` per `<button` senza `type=` attributo: 0 occorrenze.
3. I test esistenti di Settings passano senza modifiche.
4. Il comportamento del pulsante "Salva profilo" è invariato.
