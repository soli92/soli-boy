# US-091 — EP-019 UX Audit & Design Intelligence soli-boy

## User Story

**Come** maintainer del progetto soli-boy,
**voglio** applicare il pattern EP-019 Design Intelligence Layer (art-director DSL + critic/judge)
all'intera UX dell'app,
**per** documentare formalmente le intenzioni di design, correggere i deficit UX noti e validare
la pipeline EP-018 Functional Oracle (saldo debito v2.20).

## Acceptance Criteria

1. Art-director statement prodotto: `design_&_architecture/ux-design-rationale-ep019.md`
   - Contiene: INTENT, PROBLEM, DESIGN RATIONALE, CONSTRAINTS (EP-019 Step 1)
   - Contiene: DESIGN SPEC DSL per i 3 layout principali (EP-019 Step 2)
2. Fix emulatore: scale default "auto" con maxWidth 480px — utente vede subito l'emulatore in bella vista
3. Fix TouchOverlay: portrait-flow funziona correttamente (nessuna sovrapposizione, controlli sotto schermo)
4. Tab Info & Privacy: separazione netta da Settings (LegalNotice non duplicata nel footer + panel)
5. Token audit: `design_&_architecture/solids-token-audit.md` documenta token usati vs disponibili
6. Critic report: `design_&_architecture/ep019-critic-report.md` con ≥3 finding strutturati
7. EP-018 re-check: `code_quality/reports/ep018-recheck-2026-06-15.md` con verdict pass
