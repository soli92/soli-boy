# TSK-086 — Emulator size default: aumenta visibilità default emulatore

## Context

Alla prima apertura dell'app, l'emulatore appare con dimensioni percepite come "piccole".
Il finding UX (2026-06-09) documenta: "emulatore piccolo di default". L'analisi del codice mostra che
`DEFAULT_VIDEO_SETTINGS.scale = "auto"` con `maxWidth: 480px` — questo sembra già corretto in
`useVideoSettings.ts:211-215`. Il problema potrebbe essere il CSS o l'aspect ratio collassato (altezza ~24px).

**Finding tecnico da log**: "canvas CSS 378x24px (altezza collassata)" — finding collaterale del functional oracle iter-2.

Questo TSK analizza e corregge il rendering dell'emulatore in stato idle/post-load per dare immediata
visibilità alla schermata di gioco.

## EP-019 ART-DIRECTOR STATEMENT (pre-implementazione)

**INTENT:** L'utente deve vedere l'area di gioco come elemento dominante della schermata Play, non
come un piccolo box in un angolo. L'emulatore è il prodotto — deve essere "emulator-first".

**PROBLEM:** Il canvas dell'emulatore collassa in altezza (24px) in stato idle perché l'aspect-ratio
del contenitore non è forzato quando non c'è contenuto DOM visibile nel canvas-host.
Il fix di TSK-041 ha introdotto `position:absolute; inset:0` sull'host — se il parent `.sb-screen`
non ha altezza esplicita (viene dal content), l'host si azzera. Il `aspectRatio: DEFAULT_SCREEN_ASPECT_RATIO`
aggiunto in TSK-036 dovrebbe risolvere, ma potrebbe mancare in certi stati.

**DESIGN RATIONALE:** La correzione deve garantire che `.sb-screen` abbia sempre un aspect-ratio
visibile (3/2) anche con scale=auto, così il canvas-host absolute riempie uno spazio visibile.
Non si aumenta la scala di default (auto è corretto); si garantisce che l'aspect-ratio sia applicato
SEMPRE, non solo quando `s.aspect === "original"`.

**CONSTRAINTS:**
- Non rompere i test esistenti (368 test passanti)
- Non modificare la logica di scala numerica (1x..5x)
- Non toccare il canvas o l'engine — solo il CSS del contenitore
- Retrocompatibilità: le preferenze persistite devono continuare a funzionare
