# TSK-069 — Privacy policy on-device: comunicazione in-app e informativa utente

## Context

US-033 richiede che la policy di privacy on-device sia comunicata all'utente. Il
meccanismo di avviso legale esiste già (US-006, TSK-006: avviso no-copyright nel
`FileLoader`). Questo task aggiunge una informativa sintetica sulla privacy (dati solo
on-device) visibile all'utente, nella stessa area o in una sezione dedicata di Settings.
[^src: management/kanban/EP-008-conformita-e-pubblicazione-store/US-033-privacy-on-device/US-033.md §Acceptance Criteria]

## Technical Specs

- Componente `PrivacyNotice` (o sezione in `Settings`):
  - Testo: "Tutti i tuoi dati (ROM, salvataggi, configurazioni) restano sul tuo
    dispositivo. Nessun file viene inviato a server esterni."
  - Mostrato alla prima apertura dell'app (se non già accettato) + sempre disponibile
    in Settings → "Privacy".
  - Persistenza dell'accettazione: `StoragePort.setConfig('privacy-ack', 'true')`.
- Stile: usa token solids, coerente con il design system.
- L'avviso non deve bloccare l'accesso all'app (non è un paywall).

## Implementation Steps

1. Creare componente `PrivacyNotice.tsx` con testo on-device.
2. In `App.tsx`: al mount, leggere `getConfig('privacy-ack')` → se null → mostrare il notice.
3. Al dismiss dell'utente → `setConfig('privacy-ack', 'true')`.
4. Aggiungere sezione "Privacy" in `Settings` con il notice sempre disponibile.
5. Unit test: mock `getConfig` → null → PrivacyNotice visibile; accettazione → `setConfig`
   chiamato.

## DoD

- [ ] `PrivacyNotice` mostrato alla prima apertura e disponibile in Settings.
- [ ] L'accettazione è persistita e non mostrata di nuovo.
- [ ] Testo esplicito sulla privacy on-device.
- [ ] Stile con token solids.
- [ ] Build typecheck + unit test verdi.

## Dependencies

- TSK-002 (`StoragePort.setConfig`).
