# US-033 — Privacy: dati e salvataggi solo on-device

## Descrizione
Come giocatore, voglio che i miei dati di gioco e salvataggi restino sul dispositivo, affinché nessun mio file sia inviato a server esterni.

## Business Rules
- Tutti i dati di gioco e i salvataggi restano sul dispositivo dell'utente.
- Nessun invio dei file dell'utente a server esterni; il core è eseguito in contesto isolato.

[^src: wiki/concepts/persistenza-locale.md §Dettaglio]

## Acceptance Criteria
- [ ] In tutte le versioni (web, desktop, mobile) i file utente e i salvataggi non vengono inviati a server esterni.
- [ ] Il core di emulazione è eseguito in un contesto isolato.
- [ ] La policy di privacy on-device è comunicata all'utente.
