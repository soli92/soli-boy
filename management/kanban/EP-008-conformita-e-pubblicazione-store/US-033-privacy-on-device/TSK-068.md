# TSK-068 — Privacy audit: verifica invariante on-device su tutti i target

## Context

US-033 richiede che in tutte le versioni i file utente e i salvataggi non vengano inviati
a server esterni. L'invariante è dichiarata in StoragePort (`design_&_architecture/api_specs/storage-port.md §Invarianti`) e in ADR-002. Questo task produce una verifica
sistematica (audit statico + test) che l'invariante sia rispettata. [^src: management/kanban/EP-008-conformita-e-pubblicazione-store/US-033-privacy-on-device/US-033.md §Acceptance Criteria]

## Technical Specs

- **Audit statico**: grep sul codebase per chiamate `fetch`, `XMLHttpRequest`, `axios`,
  WebSocket, `navigator.sendBeacon` — nessuna deve trasmettere dati ROM/save/config.
  Le sole chiamate di rete legittime: CDN assets (JS/CSS statici) + Gamepad API polling.
- **Test e2e**: intercettare traffico di rete in Playwright (`page.on('request', ...)`)
  durante il flusso carica-ROM → avvia gioco → salva stato → esporta save.
  Asserire che nessuna richiesta contenga payload binario / dati utente.
- **Documentazione**: aggiungere `e2e/privacy-audit.e2e.ts` con asserzione esplicita
  "nessuna richiesta verso origin != localhost durante il flusso di gioco".
- Coprire anche il `NativeFsAdapter` (TSK-054): verifica che le chiamate IPC scrivano
  solo su filesystem locale e non su URL remoti.

## Implementation Steps

1. Grep automatico: script/test che lista tutte le chiamate di rete nel sorgente.
2. Creare `e2e/privacy-audit.e2e.ts`:
   - Intercettare tutte le richieste con `page.route('**', ...)`.
   - Eseguire il flusso completo (carica ROM → avvia → salva stato).
   - Asserire `requests.filter(r => !r.url().includes('localhost')).length === 0`.
3. Produrre un report testuale nella DoD (output del test).

## DoD

- [ ] Test `privacy-audit.e2e.ts` verde: nessun dato utente inviato in rete.
- [ ] Grep statico: nessuna chiamata di rete verso origine remota nel dominio/storage.
- [ ] Il core di emulazione (WASM) non ha accesso a rete (verifica nel test).
- [ ] Report di audit presente come commento nel file e2e.

## Dependencies

- TSK-054/TSK-055 (NativeFsAdapter in scope per l'audit).
- TSK-031 (`SaveService` + export).
