# TSK-070 — Avviso legale in-app: no ROM protette (Play Store / App Store compliance)

## Context

US-034 richiede che l'app non veicoli contenuti protetti e mostri l'avviso legale
in-app. L'avviso no-copyright esiste già nel `FileLoader` (TSK-006, US-006) per il
caricamento file. Questo task estende/consolida la comunicazione legale per soddisfare
i requisiti di pubblicazione degli store (Google Play + App Store richiedono che gli
emulatori dichiarino esplicitamente di non distribuire ROM/BIOS protetti). [^src: management/kanban/EP-008-conformita-e-pubblicazione-store/US-034-conformita-store/US-034.md §Business Rules]

## Technical Specs

- Verificare che l'avviso no-copyright di TSK-006 sia presente e visibile nella versione
  mobile (WebView Capacitor).
- Aggiungere nella schermata About/Settings:
  - Testo: "Soli-boy non include, distribuisce né supporta ROM o BIOS coperti da
    copyright. Usa solo file di tua legittima proprietà."
  - Link/testo per la policy di privacy on-device (collegato a TSK-069).
- Aggiungere `privacy_policy_url` nei metadati app (per submission store):
  documentato nel `README.md` interno o in un runbook, non nell'app stessa (l'URL
  specifico sarà definito dall'owner — gate umano per la submission).
- Test: asserire che il testo dell'avviso legale sia presente nel DOM.

## Implementation Steps

1. Creare (o aggiornare) sezione "About / Legale" in `Settings`.
2. Aggiungere testo avviso no-ROM protette.
3. Collegare al `PrivacyNotice` (TSK-069).
4. Unit/e2e test: asserire testo avviso nel DOM di Settings.

## DoD

- [ ] Avviso legale no-ROM protette visibile in Settings → Legale.
- [ ] Avviso presente anche nella versione mobile (WebView).
- [ ] Test verde (presenza testo nel DOM).
- [ ] Build typecheck pulito.

## Dependencies

- TSK-006 (avviso FileLoader esistente).
- TSK-069 (PrivacyNotice).
