# TSK-096 — Fix useMemo deps stale videoPort/themePort + selectAdapter Error Boundary

## Context

Tre finding correlati in `App.tsx` (`[^src5: packages/app/src/App.tsx:55]`,
`[^src5: packages/app/src/App.tsx:102]`):

**P1-01/P1-02 (minor x2, conf. 0.85):** `App.tsx:102-105` e `App.tsx:114` creano
`videoPort` e `themePort` con `useMemo(() => makeXxxPort(selectedConfig), [])`.
Le deps sono vuote, ma `selectedConfig` è una variabile di modulo catturata al mount.
Poiché `selectedConfig` è un singleton di modulo (non muta in produzione), il problema
è pratico solo in test; tuttavia violerebbe `react-hooks/exhaustive-deps` se abilitato.

**P3-01 (major, conf. 0.85):** `App.tsx:55-60` chiama `selectAdapter()` a modulo-load
fuori da qualsiasi componente React. Se `selectAdapter()` lancia un'eccezione (es.
`window.soliboyDesktop` corrotto, errore nel `NativeFsAdapter` init), blocca l'intera
app con white screen senza Error Boundary.

## Acceptance Criteria

1. `videoPort` e `themePort` in `App.tsx` hanno deps di `useMemo` corrette: o includono
   `selectedConfig` se lo stato può variare, oppure la creazione è spostata fuori dal
   componente con documentazione esplicita del perché è safe.
2. `selectAdapter()` è invocato in modo difensivo: una eccezione è catturata e porta a
   un fallback UI "Impossibile inizializzare lo storage — ricaricare l'app" invece di
   white screen. Il fallback può essere implementato tramite Error Boundary React, tramite
   un try/catch nel modulo che imposta un flag di errore, o tramite lazy init nel componente.
3. L'app si avvia normalmente quando `selectAdapter()` non lancia (comportamento
   invariato in produzione).
4. Test di regressione: `selectAdapter` mockato per lanciare → l'app mostra il messaggio
   di fallback, non una pagina bianca.
5. Test esistenti di App.tsx passano senza modifiche.

## DoD

- [ ] `useMemo` deps di `videoPort` e `themePort` corrette o documentate
- [ ] `selectAdapter()` protetto da crash totale con fallback UI
- [ ] Test regressione "selectAdapter throw → fallback" aggiunto
