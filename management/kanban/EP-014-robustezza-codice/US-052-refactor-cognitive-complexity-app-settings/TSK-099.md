# TSK-099 — Fix unsafe Error cast + test isolamento nuovi hook

## Context

**P2-06 (minor, conf. 0.90):** `Settings.tsx:260-264` usa `(e as Error).message`
nel blocco `catch` (`[^src5: packages/app/src/components/Settings/Settings.tsx:260]`).
Il cast `as Error` su `unknown` non è type-safe: se `e` non è un'istanza di `Error`
(es. un oggetto o una stringa), `.message` potrebbe essere `undefined`.

Questo TSK:
1. Corregge tutti i cast non sicuri `(e as Error).message` in `Settings.tsx` e nel
   hook `useSaveData` (estratto in TSK-098) con il pattern `e instanceof Error ? e.message : String(e)`.
2. Aggiunge test unitari per `useTabPause` e `useSaveData` in isolamento.

## Acceptance Criteria

1. Tutti i blocchi `catch` in `Settings.tsx` (inclusi quelli migrati in `useSaveData`)
   usano `e instanceof Error ? e.message : String(e)` o pattern equivalente type-safe.
   Nessun `(e as Error).message` residuo nel file.
2. Test unitario `useTabPause`: mockato con engine stub + `activeTab` simulato.
   Verificare almeno: tab change play→settings pausa engine; tab change settings→play
   riprende engine; nessun resume su engine non configurato (guard).
3. Test unitario `useSaveData`: mockato con `SaveDataPort` fake.
   Verificare almeno: `refresh` chiama `listSaveStates`; `handleExport` con ID valido
   chiama `exportSaveState`; errore in `importSave` aggiorna `message` con kind "error".
4. Coverage minima: rami principali (resume, pause, error, no-rom) coperti.
5. Tutti i test pre-esistenti passano.
