# TSK-121 — Settings: aggiungere "l" e "r" alla lista pulsanti rimappabili

## Context

Il componente Settings espone una lista di pulsanti rimappabili (`BUTTONS` array, riga ~60). L e R non vi compaiono. Questo task li aggiunge, rendendo possibile la rimappatura personalizzata da parte del giocatore.
[^src: management/kanban/EP-018-controlli-shoulder-l-r/US-064-rimappatura-l-r-settings/US-064.md §AC]

## Technical Specs

- **FE:** `packages/app/src/components/Settings/Settings.tsx` (o file equivalente che definisce `BUTTONS`)
  - Aggiungere `'l'` e `'r'` all'array `BUTTONS` (o struttura analoga), mantenendo l'ordine logico (es. dopo i 4 tasti face, prima o dopo Start/Select secondo convenzione GBA).
  - L'UI di rimappatura esistente deve renderizzare le nuove voci senza modifiche al componente di rendering (se il pattern è data-driven, solo il dato cambia).
- **Nessuna modifica al backend di storage**: il profilo persistito già accetta chiavi arbitrarie.

## Implementation Steps

1. Aprire `Settings.tsx`, individuare l'array `BUTTONS`.
2. Appendere `{ id: 'l', label: 'L' }` e `{ id: 'r', label: 'R' }` (o la forma dati usata dagli altri pulsanti).
3. Verificare che l'UI rimappatura mostri le due nuove voci e che il salvataggio profilo funzioni.
4. Eseguire `npm test` dalla cartella `packages/app` e verificare 0 regressioni.

## Definition of Done

- [x] `BUTTONS` (o equivalente) include `l` e `r`.

- [x] La rimappatura persiste al reload (profilo salvato correttamente).
- [x] Nessuna regressione sulla rimappatura degli altri pulsanti.
- [ ] Code review approvata.
