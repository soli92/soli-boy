# TSK-124 — Test integrazione/e2e: L/R tastiera, gamepad mock, touch GBA, overlay GB

## Context

Task di chiusura della wave: verifica end-to-end che L/R siano ricevuti dalla pipeline completa (tastiera → engine, gamepad → engine, touch → engine) e che l'overlay touch mostri i pulsanti correttamente per GBA (presenti) e GB (assenti o no-op secondo piattaforma).

## Technical Specs

- **QA — test unitari/integrazione** (`packages/app/src/**/*.test.ts`):
  - `input-mapping.test.ts`: già coperto da TSK-120; verificare che i casi L/R siano presenti.
  - `TouchOverlay.test.tsx`: già coperto da TSK-122; aggiungere eventuali casi di integrazione mancanti (es. overlay per core GB non mostra L/R).
- **QA — e2e Playwright** (`packages/app/e2e/**`):
  - Aggiungere spec e2e (o estendere spec esistente emulazione GBA) che:
    1. Carica una ROM GBA (usa ROM homebrew in `public/test-roms/`).
    2. Simula pressione tasto `q` (L) e `w` (R) con `page.keyboard.press`.
    3. Asserta che nessun errore JS viene emesso dalla pipeline input.
  - Aggiungere spec (o caso) che verifica la presenza dei pulsanti L/R nel DOM del TouchOverlay per core mgba/gambatte.
  - Aggiungere spec che verifica l'assenza o il no-op di L/R per core GB (wasmboy), coerente con la documentazione.
- Engine reale richiesto: usare `?engine=real` (come indicato in AGENTS.md).

## Implementation Steps

1. Verificare la copertura esistente in `input-mapping.test.ts` e `TouchOverlay.test.tsx` post-TSK-120/122.
2. Scrivere spec e2e GBA: keyboard L/R → no JS error.
3. Scrivere spec e2e touch overlay: pulsanti L/R presenti per mgba, assenti/no-op per wasmboy GB.
4. Eseguire `npm test` + `npm run e2e` (con `CI=1` per retry su flaky) e verificare tutto verde.

## Definition of Done

- [ ] Spec e2e: tastiera L/R su GBA → nessun errore pipeline.
- [ ] Spec e2e: TouchOverlay mostra L/R per mgba.
- [ ] Spec e2e o unit: overlay non mostra L/R (o no-op documentato) per wasmboy GB.
- [ ] `npm test` passa (0 failure, no regressioni).
- [ ] `npm run e2e` passa (con `CI=1`, max 1 retry per flaky @slow).
