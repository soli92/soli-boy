# TSK-123 — Engine pipeline: forward L/R verificato/documentato (mgba ok, wasmboy no-op GB, stub-engine)

## Context

Una volta che InputMapping emette gli eventi `l` e `r`, ogni engine deve gestirli correttamente. mgba li supporta già. wasmboy (GB/GBC) riceve il segnale ma è un no-op corretto (GB non ha shoulder fisici). Il task verifica l'end-to-end per ogni engine e documenta il comportamento atteso.
[^src: management/kanban/EP-018-controlli-shoulder-l-r/US-062-tastiera-gamepad-l-r/US-062.md §AC]

## Technical Specs

- **BE:** `packages/app/src/core/mgba-engine.ts`
  - Verificare che L/R siano già forwarded nella pipeline input (atteso: già ok). Aggiungere commento se mancante.
- **BE:** `packages/app/src/core/wasmboy-engine.ts`
  - Verificare che L/R siano ricevuti dalla pipeline input. Documentare esplicitamente il no-op con commento: `// L/R: no-op su GB/GBC (hardware non dispone di shoulder)`.
- **BE:** `packages/app/src/core/stub-engine.ts` (o mock engine usato nei test)
  - Verificare che lo stub accetti L/R senza errore (non deve lanciare eccezioni per input sconosciuti).
- Nessuna modifica funzionale a mgba (già corretto); solo verifica + eventuale commento.

## Implementation Steps

1. Aprire `mgba-engine.ts` — verificare che le action `l` e `r` siano passate alla WASM API; aggiungere commento se la pipeline è implicita.
2. Aprire `wasmboy-engine.ts` — localizzare dove gli input vengono forwarded; aggiungere commento no-op esplicito per L/R.
3. Verificare lo stub engine: se c'è un switch/map di action, aggiungere case `l` e `r` (anche solo no-op) per evitare warning/errori runtime.
4. Eseguire `npm test` e verificare 0 regressioni.

## Definition of Done

- [ ] mgba-engine: pipeline L/R verificata (no regression, commento se necessario).
- [ ] wasmboy-engine: no-op L/R documentato con commento esplicito.
- [ ] stub-engine: accetta L/R senza errore.
- [ ] `npm test` passa senza nuovi failure.
- [ ] Code review approvata.

## Dependencies

- TSK-120 — le action `l` e `r` devono esistere nel mapping prima di poterne verificare il forward negli engine
