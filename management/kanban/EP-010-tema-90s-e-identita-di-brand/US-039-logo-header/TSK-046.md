# TSK-046 — Logo Soli-boy nell'header della schermata Library (US-039)

## Context

US-039 richiede che l'header della schermata Library (e per estensione Player e
Settings, se previsto dai mockup) mostri il logo Soli-boy. Gli SVG sono stati
copiati in `src/assets/` da TSK-042. La variante monocromatica (`soliboy-logo-mono.svg`)
eredita il colore dal contenitore via `currentColor`, garantendo coerenza col
tema SoliDS applicato. [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-039-logo-header/US-039.md §Business Rules]

## Technical Specs

### Scelta variante

Usare `soliboy-logo-mono.svg` importata come componente React (Vite supporta
`?react` per SVG tramite `@vitejs/plugin-react`). Alternativa: importare come
URL (`?url`) e usarla come `<img src={...}>` con `aria-label`. La variante mono
è preferita per coerenza multi-tema (`currentColor` adapts a tutti i temi SoliDS).

**Assunzione annotata:** i mockup citati in US-039 non sono leggibili direttamente
come artefatti in questo contesto. Si assume che il logo vada nell'header della
Library accanto alle azioni "Carica ROM" / impostazioni, in linea con il pattern
dichiarato. Se il mockup mostra una disposizione diversa (logo separato, in alto al
centro, ecc.), l'impl va adattata senza impatto sui TSK precedenti.

### Modifica Library.tsx

Aggiungere un `<header>` (o `<div role="banner">`) in cima alla Library con:
- `<SoliboyLogo aria-label="Soli-boy" className="sb-logo" />` (SVG inline React)
  oppure `<img src={logoUrl} alt="Soli-boy" className="sb-logo" />` (import URL)
- Nessun hard-coding di colori: il logo mono usa `currentColor` (tema SoliDS)
- CSS scoped `.sb-logo { height: 2rem; width: auto; }` (dimensione minima ≥ 16px
  per leggibilità brand — AC US-039)

### Non duplicare favicon/manifest

Il logo SVG in header è una variante distinta dagli asset di `public/` usati da
TSK-043 e TSK-045; non sostituisce né duplica quelli. Gli AC di US-039 lo
confermano esplicitamente. [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-039-logo-header/US-039.md §Acceptance Criteria]

## Definition of Done

- [ ] `Library.tsx` mostra il logo Soli-boy nell'header (variante mono SVG)
- [ ] Il logo ha `aria-label` o `alt` = "Soli-boy" (accessibilità)
- [ ] Su tema `90s-party` il logo è visibile con contrasto adeguato (currentColor)
- [ ] Su tema `dark` il logo è visibile (currentColor adatta il colore)
- [ ] Nessun colore hex hard-coded nel componente (solo variabili DS o currentColor)
- [ ] Height ≥ 16px (leggibilità brand minima dichiarata)
- [ ] typecheck OK; test Library.tsx: nessuna regressione (logo mockato se necessario)
