# TSK-045 — Web app manifest (manifest.webmanifest) + link in index.html (US-038)

## Context

US-038 richiede un web app manifest che abiliti l'installazione come PWA con
nome, icone e colori di brand. Gli asset sono già disponibili in `public/` dopo
TSK-042; `index.html` è già aggiornato con i link favicon da TSK-043. [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-038-web-app-manifest/US-038.md §Business Rules]

## Technical Specs

### File: packages/app/public/manifest.webmanifest

```json
{
  "name": "Soli-boy",
  "short_name": "Soli-boy",
  "description": "Emulatore retro multipiattaforma — web, desktop, mobile.",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#0d0d0d",
  "theme_color": "#ff00cc",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
    {
      "src": "/icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "maskable"
    }
  ]
}
```

**Note palette:** `background_color: "#0d0d0d"` (fondo scuro brand) e
`theme_color: "#ff00cc"` (accento retro-neon, palette `90s-party` / cyberpunk
di SoliDS). Valori ancorati alla palette documentata nel brand kit — non inventati. [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-038-web-app-manifest/US-038.md §Business Rules]

**Assunzione annotata:** i valori esatti di `background_color` e `theme_color`
sono dedotti dalla palette documentata nel brand kit (fondo scuro + accento neon).
Se l'owner ha valori hex diversi da usare, aggiornare il manifest senza impatto
sugli altri task.

### Link in index.html

Aggiungere nel `<head>`:

```html
<link rel="manifest" href="/manifest.webmanifest" />
<meta name="theme-color" content="#ff00cc" />
```

Il manifest non interferisce con i confezionamenti Electron/Capacitor: viene
semplicemente ignorato nel contesto di shell nativa. [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-038-web-app-manifest/US-038.md §Business Rules]

## Definition of Done

- [ ] `packages/app/public/manifest.webmanifest` creato con `name`, `icons` (almeno
      192 e 512), `theme_color`, `background_color`
- [ ] `index.html` contiene `<link rel="manifest">` e `<meta name="theme-color">`
- [ ] Build produce il manifest nella radice del dist (Vite copia `public/` asis)
- [ ] In Chromium DevTools → Application → Manifest: nessun errore, icone caricate
- [ ] Gli asset referenziati dal manifest sono quelli copiati in TSK-042 (no duplic.)
