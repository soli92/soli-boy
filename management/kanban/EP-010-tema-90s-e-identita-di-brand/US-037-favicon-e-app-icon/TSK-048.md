# TSK-048 — E2e smoke test brand (favicon, manifest, logo header) (US-037/038/039)

## Context

TSK-043 (favicon), TSK-045 (manifest) e TSK-046 (logo header) introducono gli
asset brand nell'app. Un test e2e Playwright in Chromium verifica che questi
artefatti siano presenti e raggiungibili a runtime — prevenendo regressioni
silenti (es. path errate, file non inclusi nel build). [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-037-favicon-e-app-icon/US-037.md §Acceptance Criteria] [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-038-web-app-manifest/US-038.md §Acceptance Criteria]

## Technical Specs

File: `packages/app/e2e/brand.e2e.ts`

### Test 1 — favicon presente

```ts
test("favicon dichiarata in head", async ({ page }) => {
  await page.goto("/");
  const faviconHref = await page.locator('link[rel="icon"]').first().getAttribute("href");
  expect(faviconHref).toBeTruthy();
});
```

### Test 2 — manifest dichiarato e raggiungibile

```ts
test("manifest.webmanifest raggiungibile", async ({ page }) => {
  await page.goto("/");
  const manifestHref = await page.locator('link[rel="manifest"]').getAttribute("href");
  expect(manifestHref).toBeTruthy();
  // Verifica HTTP 200 sul manifest
  const resp = await page.request.get(manifestHref!);
  expect(resp.status()).toBe(200);
  const body = await resp.json();
  expect(body.name).toBe("Soli-boy");
  expect(body.icons?.length).toBeGreaterThanOrEqual(2);
});
```

### Test 3 — logo nell'header Library

```ts
test("logo Soli-boy visibile nella Library", async ({ page }) => {
  await page.goto("/");
  // Il logo ha aria-label="Soli-boy" (da TSK-046)
  await expect(page.getByLabel("Soli-boy")).toBeVisible();
});
```

**Nota:** i test usano il webServer Vite esistente (localhost:4173, già configurato
in `playwright.config.ts`). Nessun asset esterno necessario. Gli header COOP/COEP
sono già serviti dal webServer Vite (`vite.config.ts`) — nessuna modifica richiesta.
