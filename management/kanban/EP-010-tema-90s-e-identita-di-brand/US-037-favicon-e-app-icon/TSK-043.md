# TSK-043 — Favicon e link tag in index.html (US-037)

## Context

Cablare la favicon e le app icon di Soli-boy in `packages/app/index.html` usando
gli asset copiati da TSK-042. Attualmente `index.html` non dichiara alcun `<link
rel="icon">`: il browser usa il default generico. [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-037-favicon-e-app-icon/US-037.md §Acceptance Criteria]

## Technical Specs

Aggiungere nel `<head>` di `packages/app/index.html` i tag:

```html
<!-- Favicon standard (SVG preferita dai browser moderni, PNG come fallback) -->
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="icon" href="/favicon-32.png" type="image/png" sizes="32x32" />
<link rel="icon" href="/favicon-64.png" type="image/png" sizes="64x64" />

<!-- Apple Touch Icon -->
<link rel="apple-touch-icon" href="/icons/icon-180.png" sizes="180x180" />

<!-- Dimensioni supplementari per browser legacy -->
<link rel="icon" href="/icons/icon-16.png" type="image/png" sizes="16x16" />
<link rel="icon" href="/icons/icon-128.png" type="image/png" sizes="128x128" />
```

Tutte le path sono relative alla radice (`/`) — Vite copia `public/` nella root del
dist. Gli SVG usano `type="image/svg+xml"` (indicato come preferito per browser
moderni). La variante PNG a 32×32 rimane il fallback canonico.

**Assunzione annotata:** le dimensioni `icon-16.png` e `icon-128.png` non sono
esplicitamente citate negli AC di US-037 come obbligatorie, ma rientrano nel
"corredo per browser legacy" standard. Se l'owner preferisce omettere le taglie
non PWA-specifiche (lasciando solo favicon.svg + 32 + 180 + 192 + 512 per il
manifest), TSK-043 è modificabile senza impatto sugli altri task.

## Definition of Done

- [x] `packages/app/index.html` contiene `<link rel="icon">` per le varianti
      SVG, PNG 32×32, PNG 64×64
- [x] `packages/app/index.html` contiene `<link rel="apple-touch-icon">` per icon-180
- [x] `npm run build` produce la build senza errori; le favicon sono nel dist
- [x] Aprendo l'app in Chromium, il tab mostra la favicon Soli-boy (verifica visiva)
