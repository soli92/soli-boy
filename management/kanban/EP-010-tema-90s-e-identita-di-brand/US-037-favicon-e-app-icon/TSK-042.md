# TSK-042 — Copia brand asset in packages/app/public

## Context

I brand asset del kit Soli-boy esistono in `raw/soliboy-brand/` (L1, read-only per policy
R.1). Perché i task successivi (TSK-043 favicon in HTML, TSK-044 theme selector, TSK-045
manifest, TSK-046 logo header) possano referenziarli a runtime dal frontend, gli asset
vanno copiati (NON referenziati da `raw/`) in `packages/app/public/`. Questo task è il
prerequisito fisico per tutti i task brand EP-010. [^src: management/kanban/EP-010-tema-90s-e-identita-di-brand/US-037-favicon-e-app-icon/US-037.md §Business Rules]

## Technical Specs

Struttura target in `packages/app/public/`:

```
public/
  favicon.svg            ← copia di raw/soliboy-brand/svg/soliboy-favicon.svg
  favicon-32.png         ← copia di raw/soliboy-brand/png/favicon-32.png
  favicon-64.png         ← copia di raw/soliboy-brand/png/favicon-64.png
  icons/
    icon-16.png          ← raw/soliboy-brand/png/icon-16.png
    icon-32.png          ← raw/soliboy-brand/png/icon-32.png
    icon-48.png          ← raw/soliboy-brand/png/icon-48.png
    icon-64.png          ← raw/soliboy-brand/png/icon-64.png
    icon-128.png         ← raw/soliboy-brand/png/icon-128.png
    icon-180.png         ← raw/soliboy-brand/png/icon-180.png
    icon-192.png         ← raw/soliboy-brand/png/icon-192.png
    icon-256.png         ← raw/soliboy-brand/png/icon-256.png
    icon-512.png         ← raw/soliboy-brand/png/icon-512.png
    icon-1024.png        ← raw/soliboy-brand/png/icon-1024.png
    soliboy-icon.svg     ← raw/soliboy-brand/svg/soliboy-icon.svg
```

Gli SVG logo (horizontal / mono) vanno invece in `packages/app/src/assets/` perché
importati come componenti React in TSK-046:

```
src/assets/
  soliboy-logo-horizontal.svg  ← raw/soliboy-brand/svg/soliboy-logo-horizontal.svg
  soliboy-logo-mono.svg        ← raw/soliboy-brand/svg/soliboy-logo-mono.svg
```

**Nota:** nessun file di `raw/` è modificato (R.1). Il task è una pura operazione
di copia; gli asset copiati entrano nel VCS di `packages/app` (non in `raw/`).

## Definition of Done

- [ ] Directory `packages/app/public/icons/` creata e popolata con i PNG elencati
- [ ] `favicon.svg`, `favicon-32.png`, `favicon-64.png` presenti in `packages/app/public/`
- [ ] Directory `packages/app/src/assets/` creata e popolata con i due SVG logo
- [ ] I file copiati sono bit-identici agli originali in `raw/soliboy-brand/`
      (nessuna ricodifica / ottimizzazione: preservare rendering pixel-art)
- [ ] `raw/` invariato (nessuna scrittura)

## Dependencies

Nessuna. Prerequisito di TSK-043, TSK-044, TSK-045, TSK-046.
