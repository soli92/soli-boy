# TSK-073 — Visual oracle render harness: pilotaggio tema per copertura dark

## Context

La prima Visual Verification col nuovo agente v2.17 (`/visual-oracle TSK-069`) ha rilevato che
gli screenshot `light` e `dark` sono **byte-identici** (stesso md5): l'app non reagisce a
`prefers-color-scheme`, perché il tema è controllato da un theme selector esplicito persistito
(TSK-044), non dal media query OS. Di conseguenza `page.emulateMedia({colorScheme})` non commuta
il tema e la copertura **dark** del visual oracle è un blind-spot. È una limitazione del **render
harness**, non un difetto dei componenti FE.
[^src: code_quality/reports/TSK-069-visual-iter-1.md §Difetti rilevati]

## Technical Specs

- Fornire un **helper Playwright riusabile** (es. `packages/app/e2e/helpers/set-theme.ts`) che,
  dato un `Page`, imposti il tema applicativo **prima** dello screenshot/navigazione:
  - scrivendo la config persistita del tema (la stessa chiave usata da `makeThemePort` /
    `useTheme` di TSK-044 in IndexedDB — verificare la chiave canonica nel codice, non assumere),
    **oppure** pilotando il theme selector UI in modo deterministico.
- L'helper deve coprire almeno `light` e `dark` e degradare in modo esplicito (fail-loud) se la
  chiave/UI del tema cambia, così da non reintrodurre silenziosamente il blind-spot.
- Documentare nel runbook [`wiki/runbooks/visual-oracle-installation.md`](../../../../wiki/runbooks/visual-oracle-installation.md)
  che, per soli-boy, il tema va pilotato via questo helper (non via `prefers-color-scheme`).
- Nessun cambio ai componenti FE: scope esclusivamente di test-harness/tooling.

## Implementation Steps

1. Individuare nel codice la chiave/canale di persistenza del tema (TSK-044: `makeThemePort`,
   `useTheme`) — single source of truth, niente assunzioni.
2. Implementare `set-theme.ts` (set `light`/`dark`) + un piccolo test e2e che verifica che il
   render in dark differisca effettivamente dal light (anti-regressione del blind-spot).
3. Aggiornare la sezione del runbook visual-oracle con la convenzione di pilotaggio tema per
   soli-boy.
4. (Opzionale) Annotare nel digest del visual oracle quando il dark è stato realmente esercitato.

## DoD

- [x] Helper Playwright che imposta il tema applicativo (`light`/`dark`) in modo deterministico.
- [x] Test e2e anti-regressione: screenshot dark ≠ light (md5/diff > 0).
- [x] Runbook visual-oracle aggiornato con la convenzione soli-boy.
- [x] Fail-loud se la chiave/UI del tema non è risolvibile (niente blind-spot silenzioso).
- [x] Typecheck + e2e verdi.

## Dependencies

- Visual Oracle v2.17 (skill `visual-oracle-protocol`, attivata in `fe_correctness`).
