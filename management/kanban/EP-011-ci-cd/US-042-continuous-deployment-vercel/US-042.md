# US-042 — Continuous Deployment del frontend su Vercel con header COOP/COEP

## Descrizione
Come maintainer di Soli-boy, voglio che il frontend dell'app sia pubblicato automaticamente su Vercel su un evento di release/tag, affinché la versione web ufficiale sia sempre allineata alla linea principale del codice e gli utenti ne abbiano accesso senza interventi manuali.

## Business Rules
- Soli-boy è distribuito anche come web application (la stessa SPA è incapsulata in Electron per il desktop e in Capacitor per il mobile). [^src: wiki/concepts/distribuzione-web-e-desktop.md §Dettaglio]
- Il prodotto utilizza core di emulazione WebAssembly che, per il threading, richiedono la configurazione degli header Cross-Origin Opener Policy (COOP) e Cross-Origin Embedder Policy (COEP) sul server web (cross-origin isolation). [^src: wiki/concepts/emulazione-via-core-wasm.md §Dettaglio]
- Il target di deploy del frontend è Vercel: il repository contiene già `packages/app/vercel.json` con la configurazione degli header COOP/COEP per il deploy; il CD non deve regredire questa configurazione.
- I dettagli operativi (trigger esatto: push su `main` vs tag `v*` vs release GitHub; ambienti preview/production; gestione segreti; dominio) non sono documentati in wiki: tracciati come gap non-bloccante `vercel-deploy-trigger-policy` su `wiki/gaps.md` da definire con l'owner prima del breakdown TSK.

## Acceptance Criteria
- [ ] Esiste un meccanismo automatico di Continuous Deployment del frontend verso Vercel attivato da un evento di release/tag (es. tag `v*` o release GitHub), come definito nella policy di trigger concordata con l'owner.
- [ ] La build pubblicata serve gli header COOP/COEP previsti dal file `vercel.json` esistente, in modo che i core WASM con threading possano essere caricati nel browser.
- [ ] Il deploy avviene solo se la CI (US-040) è verde sul commit oggetto del deploy.
- [ ] In caso di fallimento del deploy, il maintainer riceve un segnale visibile (status check / notifica) e la versione precedente resta disponibile.
