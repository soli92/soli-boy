# TSK-033 — Export/Import salvataggi (Settings 'Dati')

## Context
 [^src: management/kanban/EP-004-salvataggi/US-019-export-import/US-019.md §Acceptance Criteria]

## Definition of Done
- [x] Funzionalità implementata come da spec
  - SaveService dominio (TSK-031 esteso): `exportSaveState(id)` → JSON
    versionato `{format:"soliboy-save", version:1, kind:"saveState", romId,
    core, slot, createdAt, data: base64(blob)}` (ADR-006 §Decisione p.3).
  - SaveService dominio: `importSave(file|bytes|string)` parsing + validazione
    `format`/`version`/struttura + riassociazione ROM via storage.getRom +
    persistenza (`putSaveState` / `putSram`). Esito esplicito `ok:false` con
    reason (`invalid-file`, `format-mismatch`, `unsupported-version`,
    `rom-not-found`) — no throw, no falsi claim. Supporto anche
    `kind:"sram"` per import file SRAM.
  - Settings: sezione "Dati" con esposizione del contesto ROM corrente, select
    "Salvataggio da esportare", bottone "Esporta" (Blob → URL.createObjectURL
    → anchor.click → revokeObjectURL), input file "Importa" → `importSave`
    → messaggio `role="status"` su OK / `role="alert"` su KO (US-019 AC3).
  - App.tsx (eccezione di composizione autorizzata): `saveService` e
    `currentRom` (proiezione id+title della ROM selezionata nel Player) passati
    a `<Settings>`. Stessa istanza SaveService di TSK-032 (no duplicazioni).
- [x] Test (unit/e2e/component) verdi; typecheck OK
  - vitest: 164 test verdi (145 baseline + 12 nuovi su `save-service.test.ts`
    per export/import incl. round-trip e tutti i reason di KO + 7 nuovi
    `Settings.data.test.tsx` per controlli, export (URL.createObjectURL /
    anchor.click mockati), import OK/KO con `role="alert"`).
  - typecheck `tsc --noEmit` OK; build `vite build` OK.
  - Playwright e2e 8/8 verdi (dopo wiring App.tsx).
- [x] Nessuna regressione
  - Tutti i test pre-esistenti (incl. Settings.test, Settings.videoSettings,
    Settings.filter, SaveStatePanel, Player.*, Library.*) restano verdi.
  - Selector hygiene e2e: il titolo della ROM appare solo nelle tile Library
    e nel Player; in Settings il contesto ROM è indicato via id corto.
