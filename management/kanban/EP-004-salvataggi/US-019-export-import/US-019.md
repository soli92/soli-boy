# US-019 — Export e import salvataggi

## Descrizione
Come giocatore, voglio esportare e importare i salvataggi come file, affinché possa farne backup o trasferirli tra dispositivi.

## Business Rules
- L'utente può esportare e importare i salvataggi come file.
- All'import, il salvataggio viene riassociato al gioco corretto.

## UI Reference
[^src: wiki/concepts/persistenza-locale.md §Dettaglio]

## Acceptance Criteria
- [ ] È possibile esportare un salvataggio come file.
- [ ] È possibile importare un file di salvataggio precedentemente esportato.
- [ ] Un file di salvataggio non valido o non corrispondente produce un avviso comprensibile.
