# US-016 — Save state multipli e ripristino

## Descrizione
Come giocatore, voglio creare più save state e ripristinarli, affinché possa salvare e riprendere il gioco in qualsiasi momento.

## Business Rules
- Un save state è un'istantanea completa dello stato dell'emulatore, ripristinabile in qualsiasi momento.
- L'utente può creare save state multipli per lo stesso gioco.

[^src: wiki/concepts/save-state-e-sram.md §Contesto]

## Acceptance Criteria
- [ ] È possibile creare un save state durante l'esecuzione.
- [ ] È possibile mantenere più save state distinti per lo stesso gioco.
- [ ] È possibile ripristinare un save state e riprendere esattamente da quello stato.
