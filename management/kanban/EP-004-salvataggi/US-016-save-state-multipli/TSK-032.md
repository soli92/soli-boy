# TSK-032 — Player: pannello save state (slot Salva/Carica)

## Context
 [^src: management/kanban/EP-004-salvataggi/US-016-save-state-multipli/US-016.md §Acceptance Criteria]
 [^src: management/kanban/EP-004-salvataggi/US-018-salvataggi-associati/US-018.md §Acceptance Criteria]
 [^src: design_&_architecture/decisions/ADR-006.md §Decisione p.4]

## Implementazione

- Nuovo componente `packages/app/src/components/Player/SaveStatePanel.tsx`
  (interfaccia segregata `SaveServicePort`, sottoinsieme di `SaveService` —
  TSK-031). Consuma il dominio via porta, mai direttamente storage/engine.
- `Player.tsx` esteso con prop opzionali `saveService`, `romId`, `currentCore`:
  se `saveService` è iniettato il pannello viene reso, altrimenti il Player
  resta backward-compatible (test legacy invariati).
- `App.tsx` compone `new SaveService(storage)` (memo) e passa `saveService`,
  `romId={selected.id}`, `currentCore={selected.core}` al `<Player>`. Lo
  `storage` (IndexedDBAdapter) implementa già `SaveStoragePort` (port.ts):
  nessun nuovo adapter, niente storage paralleli.
- UI: 3 slot per default (`slots` configurabile). Per ogni slot: Salva,
  Carica, Elimina + meta (timestamp). Usa solo classi `sb-*` / `sd-*` del
  design system esistente (`styles/solids-theme.css`).
- Gate (US-016 AC1 "durante l'esecuzione" + US-018 AC2 "solo i saves del
  gioco"): pannello disabilitato se non running, se manca `romId`, oppure
  se `engine.capabilities.saveStates === false` (nota onesta, no claim falsi).
- ADR-006 §Conseguenze: `engine-mismatch` su Carica → messaggio chiaro via
  `role="alert"`, no crash, lista ri-letta. `not-found` → idem + refresh.
- A11y: `role="region"` con `aria-label="Save state"`; bottoni con
  `aria-label` esplicito ("Salva nello slot N", "Carica slot N", "Elimina
  slot N"). Stato disabilitato veicolato da `disabled` HTML + `data-disabled`.

## Test

- `SaveStatePanel.test.tsx` (9 test): Salva chiama saveState con (engine,
  romId, slot); lista mostra solo i save della ROM corrente (US-018);
  Carica chiama loadState con (engine, id, currentCore); engine-mismatch
  → messaggio chiaro + region intatta; Elimina rimuove + refresh; pannello
  disabilitato senza romId / senza running / con saveStates=false.
- `Player.test.tsx` esteso (+2 test): senza `saveService` il pannello non
  è reso (backward compat); con `saveService` reso + Salva chiama il
  servizio quando il gioco è in esecuzione.
