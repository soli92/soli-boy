# TSK-041 — Bugfix: il canvas sparisce dopo load del save state (WasmBoy)

## Context
Bug runtime scoperto dall'e2e reale TSK-034 (gap `wasmboy-loadstate-canvas-lost`):
dopo `Carica slot`, il canvas `.sb-screen canvas` scompare dal DOM. Blocca US-016 AC3
("ripristinare un save state e riprendere esattamente da quello stato"). Il save (AC1/AC2)
è verificato verde. [^src: management/kanban/EP-004-salvataggi/US-016-save-state-multipli/US-016.md §Acceptance Criteria]

## Ipotesi tecnica
`.sb-screen` (screenRef) è passato come container all'engine **e** contiene figli React
(testo placeholder + overlay scanline). Il `<canvas>` appeso imperativamente da WasmBoy è
un nodo fuori dal controllo di React; un re-render che riconcilia i figli di `.sb-screen`
(o il flusso loadState) può rimuoverlo. Fix: isolare il canvas in un host React-vuoto
dedicato dentro `.sb-screen` (nessun figlio React nello stesso nodo del canvas).

## Definition of Done
- [x] Canvas isolato in un host React-vuoto; engine riceve quell'host come container
- [x] e2e `emulation-save.e2e.ts`: rimosso il `test.fixme`, il test load passa DAVVERO
      (canvas resta visibile, nessun `role=alert`) — verifica eseguita con `npm run e2e`
- [x] Gap `wasmboy-loadstate-canvas-lost` chiuso; TSK-034 → done
- [x] typecheck + unit + build verdi, nessuna regressione (6→8 e2e verdi)

## Esito (2026-06-01)
Fix applicato in `packages/app/src/components/Player/Player.tsx`:
- Aggiunto `canvasHostRef` su un nuovo `<div className="sb-canvas-host" />` reso
  DENTRO `.sb-screen` come PRIMO figlio, **senza alcun figlio React** dichiarato.

  far riempire il box di `.sb-screen` (resa visiva invariata). Il selettore e2e
  `.sb-screen canvas` continua a matchare (il canvas resta discendente).
- `core/wasmboy-engine.ts` non toccato (R.8 scope chiuso: bastava l'isolamento FE).
- Test placeholder testuale e overlay scanline restano fratelli dell'host (NON
  figli dell'host) dentro `.sb-screen`, così la regola CSS scoped per
  `image-rendering` / `object-fit` / `.sb-scanline` resta valida.
