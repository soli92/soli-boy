# US-029 — Caricamento ROM/BIOS da dispositivo e cloud

## Descrizione
Come giocatore su mobile, voglio caricare ROM e BIOS dal file system del dispositivo e dai provider cloud di sistema, affinché possa portare i miei file nell'app.

## Business Rules
- L'app carica ROM e BIOS dal file system del dispositivo e dai provider cloud di sistema.

## UI Reference
[^src: wiki/concepts/controlli-touch.md §Contesto]

## Acceptance Criteria
- [ ] È possibile selezionare ROM/BIOS dal file system del dispositivo.
- [ ] È possibile selezionare ROM/BIOS da un provider cloud di sistema.
- [ ] I file caricati confluiscono nella stessa libreria delle altre versioni.
