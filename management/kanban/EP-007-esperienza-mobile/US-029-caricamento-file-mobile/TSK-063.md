# TSK-063 — File picker mobile: caricamento ROM/BIOS da filesystem e provider cloud (Capacitor)

## Context

US-029 richiede che su mobile sia possibile selezionare ROM e BIOS dal filesystem del
dispositivo e da provider cloud di sistema (es. Google Drive, iCloud). Su web il
`FileLoader` usa `<input type="file">` — questo meccanismo funziona anche nel WebView
Capacitor e include automaticamente i provider cloud di sistema su Android e iOS.
Il plugin `@capacitor/filesystem` è necessario per leggere file da path nativi se il
dialog restituisce path (non blob). [^src: management/kanban/EP-007-esperienza-mobile/US-029-caricamento-file-mobile/US-029.md §Business Rules]

## Technical Specs

- **Verifica**: `<input type="file" accept=".gb,.gbc,.gba,…">` nel `FileLoader` esistente
  apre il document picker nativo su Android/iOS inclusi i provider cloud — nessuna modifica
  all'elemento `<input>`.
- Se Capacitor restituisce un file URI (non un `File` blob), leggere il contenuto con
  `@capacitor/filesystem Filesystem.readFile()` → convertire in `Blob`.
- Aggiornare il `FileLoader` per gestire entrambe le strade (File API web / Capacitor path).
- I file caricati confluiscono nel flusso esistente: `PlatformRecognition` → `LibraryService`
  → `StoragePort` (identico web/desktop). [^src: design_&_architecture/decisions/ADR-002.md §Conseguenze]

## Implementation Steps

1. Verificare in emulatore Android che `<input type="file">` apra il picker di sistema
   incluso iCloud/Drive.
2. Se necessario, aggiungere handler Capacitor nel `FileLoader`:
   - Rilevare contesto Capacitor (`Capacitor.isNativePlatform()`).
   - Se il file è un URI, leggere con `Filesystem.readFile` e creare un `File` object.
3. Unit test: mock `Capacitor.isNativePlatform() = true` + `Filesystem.readFile` → verifica
   che il `File` object risultante sia passato correttamente a `PlatformRecognition`.
4. Smoke test su emulatore (umano): selezione file da iCloud/Drive → libreria aggiornata.

## DoD

- [ ] Su Android: selezione ROM da filesystem dispositivo e da Google Drive → libreria ok.
- [ ] Su iOS: selezione ROM da Files (iCloud Drive incluso) → libreria ok.
- [ ] I file caricati confluiscono nella stessa libreria delle altre versioni.
- [ ] Unit test verde.
