# TSK-178 — Esecuzione validazione Android su device fisico [HUMAN]

## Context

US-111 — validazione su dispositivo Android reale dopo EP-022. `consumer: human` — richiede device fisico, Android Studio e giudizio qualitativo. [^src: US-111 §Business Rules]

## Technical Specs

- Seguire [`store-assets/device-validation-checklist.md`](../../../../store-assets/device-validation-checklist.md)
- Runbook operativo: [`wiki/runbooks/android-device-validation-runbook.md`](../../../../wiki/runbooks/android-device-validation-runbook.md)
- Pre-check agent: `npm run e2e:android` (profilo Pixel 7 — non sostituisce device fisico)
- Build: `./scripts/android-device-prepare.sh` → `npm run cap:open:android` o `cap:run:android`
- Eseguire matrice test (portrait + landscape, 4 tab, emulazione GB con `dmg-acid2.gb`)
- Compilare `store-assets/android-validation-report.md` dal template TSK-177
- Verificare esplicitamente: tab Play cliccabile in portrait (anti-regressione US-105)

## DoD

- [ ] Emulazione GB verificata su device reale (canvas renderizzato)
- [ ] Eventuali blocker documentati come issue/gap in report
