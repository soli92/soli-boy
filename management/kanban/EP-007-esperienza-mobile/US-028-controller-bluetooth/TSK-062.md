# TSK-062 — Bluetooth controller su mobile: rilevamento Gamepad API + auto-hide TouchOverlay

## Context

US-028 richiede che un controller Bluetooth collegato venga riconosciuto e che i controlli
touch possano essere nascosti automaticamente. Tech stack specifica "Gamepad API" per input
da controller; ADR-003 cita "controller BT su mobile" nella lista sorgenti `bindInput`.
L'`InputMapping` esiste già (TSK-016) e gestisce la Gamepad API su web/desktop;
va validato il path mobile e aggiunto l'auto-hide. [^src: design_&_architecture/api_specs/core-wrapper.md §Operazioni]

## Technical Specs

- La Gamepad API web è disponibile nel WebView Capacitor su Android e iOS (RNFM-02).
- Nessun plugin Capacitor aggiuntivo necessario per il rilevamento: usare
  `window.addEventListener('gamepadconnected', ...)` / `gamepaddisconnected`.
- Modifiche a `InputMapping` (o nuovo hook `useGamepadMobile`):
  - Rilevamento connessione/disconnessione Gamepad.
  - Segnalazione al `TouchOverlay`: se gamepad connesso → `setGamepadConnected(true)`.
- `TouchOverlay`: se `gamepadConnected === true` → si nasconde (CSS `visibility: hidden`
  oppure non renderizzato). Comportamento configurabile (toggle in Settings).
- Gli input del gamepad già gestiti da `InputMapping` su web (TSK-016) — nessuna modifica
  al wiring del core.

## Implementation Steps

1. Creare hook `useGamepadDetection()`: espone `{ connected: boolean }`.
2. Integrare il hook nel `Player` e passare `connected` al `TouchOverlay`.
3. `TouchOverlay`: aggiungere prop `hideWhenGamepad` (default true) e logica di hide.
4. Aggiungere toggle "Nascondi overlay con gamepad" in Settings (US-013 Settings esistente).
5. Unit test: evento `gamepadconnected` → `connected: true` → TouchOverlay nascosto.

## DoD

- [ ] Con gamepad Bluetooth connesso, i pulsanti del controller controllano il gioco.
- [ ] I controlli touch si nascondono automaticamente (comportamento default).
- [ ] Il toggle di nascondimento è persistito nelle preferenze.
- [ ] Unit test verde.

## Dependencies

- TSK-060 (`TouchOverlay`).
- TSK-016 (`InputMapping` + Gamepad API).
