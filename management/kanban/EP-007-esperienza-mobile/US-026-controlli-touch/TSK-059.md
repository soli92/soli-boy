# TSK-059 — Capacitor: inizializzazione progetto Android + iOS e build base

## Context

ADR-001 stabilisce Capacitor come shell mobile (WebView + plugin nativi). Tech stack
conferma: "Shell mobile: Capacitor (WebView + plugin nativi, Android/iOS)". Questo task
crea il progetto Capacitor e verifica che la SPA esistente si avvii nel WebView mobile.
È il prerequisito di tutti gli altri task EP-007. [^src: design_&_architecture/decisions/ADR-001.md §Decisione]

`consumer: human` perché richiede Android Studio / Xcode + device/emulatore fisico e
gestione di certificati/SDK, che non sono disponibili all'agent.

## Technical Specs

- Dipendenze: `@capacitor/core`, `@capacitor/cli`, `@capacitor/android`, `@capacitor/ios`.
- `npx cap init` con `appId: com.soli92.soliboy`, `appName: Soli-boy`.
- `capacitor.config.ts` → `webDir: dist` (output Vite di `packages/app`).
- Plugin da installare contestualmente (usati dai task successivi):
  - `@capacitor/filesystem` (TSK-062 — file picker mobile).
  - `@capacitor/app` (TSK-064 — sospensione/ripresa).
  - `@capacitor/haptics` (TSK-065 — feedback aptico).
- `npx cap add android` + `npx cap add ios`.
- Smoke test: build Vite (`npm run build`) → `npx cap sync` → apertura su emulatore
  Android / simulatore iOS. La SPA deve renderizzarsi.

## Implementation Steps

1. Installare le dipendenze Capacitor nel workspace `packages/app`.
2. Creare `capacitor.config.ts`.
3. Aggiungere target android e ios.
4. Aggiornare il `README` (o runbook) con i comandi `cap sync` / `cap run`.
5. Verificare su emulatore Android e simulatore iOS.

## DoD

- [ ] `npx cap sync` completa senza errori.
- [ ] La SPA si apre nell'emulatore Android.
- [ ] La SPA si apre nel simulatore iOS.
- [ ] I plugin `@capacitor/filesystem`, `@capacitor/app`, `@capacitor/haptics`
  sono installati e configurati.

## Dependencies

- Nessuna dipendenza TSK (prerequisito assoluto EP-007).
- Richiede: Android Studio, Xcode, JDK — gate umano.
