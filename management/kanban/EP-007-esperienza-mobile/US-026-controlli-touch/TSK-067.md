# TSK-067 — e2e mobile smoke: TouchOverlay + sospensione/ripresa (browser/mobile sim)

## Context

Valida i comportamenti chiave di EP-007 copribili in ambiente browser (Playwright con
viewport mobile, `pointer: coarse` emulato): presenza `TouchOverlay`, input touch verso
il core, safe area layout, e pausa in background. La validazione reale su device fisico
è un gate umano (TSK-059). [^src: management/kanban/EP-007-esperienza-mobile/US-026-controlli-touch/US-026.md §Acceptance Criteria]

## Technical Specs

- Suite Playwright `e2e/mobile-touch.e2e.ts` con device emulation (`iPhone 13` o `Pixel 5`).
- Test 1: `TouchOverlay` è visibile con viewport mobile (`pointer: coarse`).
- Test 2: tap su D-pad → `sendTouchInput` chiamato (spy via `page.evaluate`).
- Test 3: `document.dispatchEvent(new Event('visibilitychange'))` con `document.hidden=true`
  → `GameSession.pause()` chiamato (spy).
- Test 4: layout portrait → safe area padding applicato (verifica CSS `env()` value).
- Engine: `StubEngine` (come tutti gli e2e deterministici).

## Implementation Steps

1. Creare `e2e/mobile-touch.e2e.ts` con device `iPhone 13`.
2. Implementare i 4 test descritti.
3. Aggiungere script `npm run e2e:mobile` con `--project=mobile`.
4. Configurare `playwright.config.ts`: progetto `mobile` con device `iPhone 13`.

## DoD

- [ ] 4 test verdi con device `iPhone 13` in Playwright.
- [ ] Nessuna regressione nei test esistenti.
- [ ] Il progetto `mobile` è aggiunto a `playwright.config.ts`.

## Dependencies

- TSK-060 (`TouchOverlay`).
- TSK-064 (safe areas).
- TSK-065 (sospensione/ripresa).
