# TSK-060 — TouchOverlay: componente D-pad + pulsanti virtuali (mobile)

## Context

US-026 richiede D-pad e pulsanti virtuali per ogni piattaforma emulata. Il contratto
`CoreWrapper.bindInput` (core-wrapper.md) include il sorgente `touch` nella firma
`bindInput(sorgente, profilo)`: InputMapping già supporta il touch come sorgente di input.
Gli input touch emettono eventi sintetici verso il core via `sendInput`. [^src: design_&_architecture/api_specs/core-wrapper.md §Operazioni]

## Technical Specs

- Componente React `TouchOverlay` (in `src/components/TouchOverlay/`):
  - Renderizzato sopra il viewport Player solo quando `isTouchDevice` è true
    (rilevato tramite `window.matchMedia('(pointer: coarse)')`).
  - D-pad: 4 direzioni (su/giù/sinistra/destra) → eventi `touchstart`/`touchend`
    mappati a `InputMapping.sendTouchInput('up'|'down'|'left'|'right', pressed)`.
  - Pulsanti virtuali: mapping per piattaforma (es. GB: A, B, Select, Start;
    GBA: A, B, L, R, Select, Start). Il set di pulsanti dipende dal `core` della sessione corrente.
  - Stile: semi-trasparente, usa token solids (`z-index`, colori, border-radius).
  - `aria-hidden="true"` (elemento esclusivamente touch, non nel tab order).
- Integrazione nel `Player`: il `TouchOverlay` è montato come child del Player.
- Nessun input verso server (privacy invariante).

## Implementation Steps

1. Creare `src/components/TouchOverlay/TouchOverlay.tsx` con D-pad + button set.
2. Creare `src/components/TouchOverlay/button-map.ts`: mappa `core → button[]`.
3. Integrare `TouchOverlay` nel `Player.tsx` (visibile solo su touch device).
4. Estendere `InputMapping.sendTouchInput` per inviare input al core tramite il metodo
   `CoreWrapper.bindInput`/`sendInput` esistente.
5. Unit test: render D-pad, touch event → `sendTouchInput` chiamato con la direzione corretta.

## DoD

- [ ] `TouchOverlay` si mostra sul Player su dispositivo touch.
- [ ] Gli input D-pad controllano il gioco (verificato con `StubEngine` e event spy).
- [ ] I pulsanti coprono tutti i comandi della piattaforma emulata corrente.
- [ ] L'overlay è `aria-hidden`, non rompe accessibilità tastiera.
- [ ] Build typecheck + unit test verdi.
