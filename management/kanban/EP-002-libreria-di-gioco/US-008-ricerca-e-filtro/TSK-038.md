# TSK-038 — Ricerca + filtro piattaforma (UI Library)

## Context
 [^src: management/kanban/EP-002-libreria-di-gioco/US-008-ricerca-e-filtro/US-008.md §Acceptance Criteria]

## Definition of Done
- [x] Funzionalità implementata come da spec
  - Campo di ricerca testuale (`<input type="search">`) sopra la griglia.
    Filtra in-memory per sottostringa case-insensitive sul titolo
    (`packages/app/src/components/Library/Library.tsx`).
  - Filtro piattaforma a chip (`role=radiogroup` con chip `role=radio`):
    "Tutte" + solo le piattaforme presenti nella libreria (GB, GBC, GBA, ARCADE),
    ordine canonico stabile.
  - Ricerca e filtro sono combinabili (intersezione dei predicati).
  - Stato vuoto dedicato "Nessun risultato per i filtri selezionati"
    (`role=status`) quando il filtro non produce match.
  - Filtri applicati con `useMemo` su `roms`/`query`/`platform` per evitare
    re-render inutili (come da nota US-008 sulla performance per liste piccole).
  - Classi DS coerenti con i mockup: `sb-search` per il campo, `sd-badge sb-chip`
    (+ `sb-chip-on` quando attivo) per i chip, `sb-grid`/`sd-card sb-game` per la
    griglia (già esistenti in `src/styles/solids-theme.css`).
  - Accessibilità: `<label for>` + `aria-label` sul campo, `role=radiogroup` con
    `aria-label`, `role=radio` + `aria-checked` sui chip; stato vuoto come
    `role=status`. Nessun endpoint custom; consumiamo solo `StoragePort.listRoms`
    già esistente (filtro lato UI in-memory, coerente con architecture-overview.md
    §EP-002).
- [x] Test (unit/e2e/component) verdi; typecheck OK
  - 8 test in `packages/app/src/components/Library/Library.test.tsx` (3 esistenti
    + 5 nuovi per US-008): filtro titolo case-insensitive, filtro piattaforma,
    combinazione titolo+piattaforma, stato vuoto, set chip presenti.
  - Suite completa: 71/71 verdi (16 file). `npm run typecheck` OK.
- [x] Nessuna regressione
  - Test esistenti del componente Library aggiornati solo per scope (uso di
    `within(grid)` per disambiguare "GBA" badge vs "GBA" chip). Nessun altro
    test toccato; build (`npm run build` → tsc + vite) OK.
  - Scope di scrittura rispettato: modifiche solo in
    `packages/app/src/components/Library/{Library.tsx,Library.test.tsx}`.

## Notes (TSK-038)
- Approccio: filtro in-memory con `useMemo`. Motivazione: il componente
  carica già l'intero array via `storage.listRoms()` in `useState` (TSK-012);
  ri-chiamare `listRoms({platform, query})` ad ogni keystroke aggiungerebbe
  un round-trip asincrono inutile e complicherebbe la gestione race. Il
  contratto `StoragePort.listRoms(filter)` rimane disponibile per usi futuri
  (es. paginazione/dataset grandi), come previsto da architecture-overview.md.
- Copertina (US-009) esplicitamente fuori scope: la tile resta titolo + badge
  piattaforma; nessuna modifica al layout del card. Vedi TSK-039.
