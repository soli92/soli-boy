# TSK-040 — Integrare il design system reale @soli92/solids

## Context
Sostituire il tema SoliDS *approssimato* (vendor dai mockup) con il pacchetto reale `@soli92/solids`, chiudendo il gap design-system-real-package. Cross-cutting su tutta la UI. [^src: management/kanban/EP-002-libreria-di-gioco/US-007-griglia-libreria/US-007.md §Acceptance Criteria]

## Technical Specs
- `npm i @soli92/solids` (quando consumabile) → in `main.tsx` `import "@soli92/solids/css/index.css"` (token/temi reali + `data-theme`).
- Rimuovere i blocchi `:root`/`[data-theme]` *colore* approssimati da `src/styles/solids-theme.css`; mantenere solo le classi app (`sb-*`) non fornite dal pacchetto (o migrarle).
- Verificare resa con tema `dark`/`cyberpunk`.

## Risoluzione blocker (Q_001 → RISOLTA)
`npm i @soli92/solids` ora risolve dal registry (1.14.1, `dist/css/*` presente). Q_001 chiusa.

## Implementazione
- `@soli92/solids@^1.14.1` in `packages/app/package.json`.
- `main.tsx`: ordine import = `solids-theme.css` (skin app) → `@soli92/solids/css/index.css` (token/temi/utilities/shadcn reali, autoritativo) → `app-extra.css` (layout app).
- `solids-theme.css`: rimossi i blocchi `:root`/`[data-theme]` *colore* approssimati; tenute classi app `sb-*`, le poche `sd-` usate dall'app e non fornite dal pacchetto (es. `sd-between`), e scale token `:root` come fallback (sovrascritto dal reale).
- Verifica: `typecheck` OK, `build` OK (CSS 62.75 kB include il DS reale), **49 unit + 6 e2e** verdi.

## Definition of Done
- [x] `@soli92/solids` installato e CSS reale importato
- [x] Tema approssimato (colore) rimosso; UI invariata; build+test verdi
- [x] Gap design-system-real-package chiuso
