# TSK-144 — Player container + HUD + controls → solids Button

## Migrazione

**`.sb-screen` wrapper:**
- Mantieni `position: relative`, `aspect-ratio: 16/10`, `overflow: hidden` — invarianti game
- Sostituisci colori/bordi/radii hardcoded con Tailwind: `bg-[var(--sd-screen-bg)] border border-border rounded-md overflow-hidden relative`

**HUD (`.sb-hud`):**
- `className="flex items-center justify-between text-xs text-muted-foreground font-mono px-2 py-1"`
- Badge fps/platform: solids `Badge variant="outline"` + `className="font-mono text-xs"`

**Player controls — mapping variant:**
| Classe attuale | solids Button |
|---|---|
| `sb-btn sb-btn-primary` (Avvia) | `Button variant="default"` |
| `sb-btn` (Pausa, Riprendi, Fast-forward, Fullscreen) | `Button variant="outline"` |
| `sb-btn sb-danger` (Arresta) | `Button variant="destructive"` |
| `sb-icon` (icon-only) | `Button variant="ghost" size="icon"` |

**SaveStatePanel:**
- Slot buttons (Load/Save) → `Button variant="outline" size="sm"`
- Delete slot → `Button variant="ghost" size="icon"` con icona Tabler `ti ti-trash`

**Rimuovere da `solids-theme.css`:** `.sb-btn`, `.sb-btn-primary`, `.sb-icon`, `.sb-danger` (dopo grep-confirm)
