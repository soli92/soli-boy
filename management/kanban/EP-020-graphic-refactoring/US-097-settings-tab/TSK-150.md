# TSK-150 — Form controls → Switch, Select, Slider, Kbd, Input

## Migrazione

**Toggle switches (`.sb-tog`):**
```tsx
<div className="flex items-center justify-between py-1.5">
  <Label htmlFor="scanline-toggle">Scanline</Label>
  <Switch id="scanline-toggle" checked={scanline} onCheckedChange={setScanline} />
</div>
```

**Dropdown selects (`.sb-sel`):**
```tsx
<Select value={scale} onValueChange={setScale}>
  <SelectTrigger className="w-[120px]"><SelectValue /></SelectTrigger>
  <SelectContent>
    <SelectItem value="2x">2×</SelectItem>
    <SelectItem value="3x">3×</SelectItem>
    <SelectItem value="fit">Adatta</SelectItem>
  </SelectContent>
</Select>
```

**Volume slider (`.sb-range`):**
```tsx
<div className="flex items-center gap-3">
  <Label>Volume</Label>
  <Slider value={[volume]} onValueChange={([v]) => setVolume(v)} min={0} max={100} step={1} className="flex-1" />
  <span className="text-sm text-muted-foreground w-8 text-right">{volume}%</span>
</div>
```

**Keymap rows (`.sb-row` + `.sb-key`):**
```tsx
<div className="flex items-center justify-between py-1.5 text-sm">
  <span>Up</span>
  <div className="flex items-center gap-2">
    <Kbd>ArrowUp</Kbd>
    <Button variant="outline" size="sm" onClick={startRemap}>Cambia</Button>
  </div>
</div>
```

**RtcSection (data/ora):**
```tsx
<div className="grid grid-cols-2 gap-3">
  <Field>
    <Label htmlFor="rtc-date">Data</Label>
    <Input id="rtc-date" type="date" value={date} onChange={...} />
  </Field>
  <Field>
    <Label htmlFor="rtc-time">Ora</Label>
    <Input id="rtc-time" type="time" value={time} onChange={...} />
  </Field>
</div>
```

**Rimuovere da `solids-theme.css`:** `.sb-tog`, `.sb-sel`, `.sb-range`, `.sb-row`, `.sb-key`, `.sb-lbl`
