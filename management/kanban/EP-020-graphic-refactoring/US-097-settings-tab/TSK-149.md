# TSK-149 — Settings sections → solids Accordion

## Context

`Settings.tsx` usa `<details>/<summary>` con CSS custom per l'animazione apertura/chiusura e un chevron CSS con `::after`. Da rimpiazzare con solids `Accordion` (Radix: keyboard ArrowDown/Up, Home/End, aria-expanded, animated content height via CSS `@keyframes`).

## Migrazione

```tsx
<Accordion type="multiple" defaultValue={["video"]} className="flex flex-col gap-2">
  <AccordionItem value="video">
    <AccordionTrigger>Resa video</AccordionTrigger>
    <AccordionContent>
      {/* contenuto sezione */}
    </AccordionContent>
  </AccordionItem>
  {/* ... altre sezioni */}
</Accordion>
```

**Sezioni da migrare:** Video, Audio, BIOS, Controlli, Aspetto, Dati + RtcSection (se visibile)

**Container sezione (`.sd-card.sb-sec`):**
- `AccordionItem` usa di default `border-b border-border`
- Per aspetto "card": wrappare in `<Card className="overflow-hidden">` oppure usare `className` su `AccordionItem`

**Rimuovere da `app-extra.css`:**
- `.sb-accordion-wrap` (wrapper custom)
- Regole chevron `summary::after { ... rotate() ... }` (Radix usa il suo ChevronDown)
- `.sb-sec`, `.sb-lbl` component-level CSS (rimpiazzati da Tailwind + Accordion)
