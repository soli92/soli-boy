# TSK-147 — Search input + platform chips → Input + ToggleGroup

## Migrazione

**Search input (`.sb-search input`):**
```tsx
<div className="flex flex-col gap-1">
  <Label htmlFor="rom-search">Cerca un gioco</Label>
  <Input id="rom-search" type="search" placeholder="Cerca un gioco…" value={query} onChange={...} />
</div>
```

**Platform filter chips (`role="radiogroup"` + `.sb-chip/.sb-chip-on`):**
```tsx
<ToggleGroup type="single" value={platform} onValueChange={setPlatform} aria-label="Filtra per piattaforma">
  <ToggleGroupItem value="all">Tutti</ToggleGroupItem>
  <ToggleGroupItem value="GB">Game Boy</ToggleGroupItem>
  <ToggleGroupItem value="GBC">Game Boy Color</ToggleGroupItem>
  <ToggleGroupItem value="GBA">Game Boy Advance</ToggleGroupItem>
  <ToggleGroupItem value="NDS">Nintendo DS</ToggleGroupItem>
  <ToggleGroupItem value="NES">NES</ToggleGroupItem>
</ToggleGroup>
```

`ToggleGroup type="single"` mappa correttamente a `role="group"` con `role="radio"` sui figli — semantica identica all'attuale `role="radiogroup"`.

**Rimuovere:** `.sb-search`, `.sd-badge.sb-chip`, `.sb-chip-on` da `solids-theme.css` e `app-extra.css` (inclusi override WCAG per `.sb-chip-on` — da sostituire con override su ToggleGroupItem attivo se necessario)
