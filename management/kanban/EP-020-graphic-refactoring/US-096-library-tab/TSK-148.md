# TSK-148 — RemoveRomConfirmDialog → AlertDialog

## Context

`RemoveRomConfirmDialog` in `Library.tsx` è attualmente implementato con un `<div>` fixed-position, backdrop overlay, focus trap manuale e handler Esc. Tutto questo viene rimpiazzato da Radix `AlertDialog` che gestisce nativamente: Portal, focus trap, Esc, backdrop, ARIA `alertdialog`.

## Migrazione

```tsx
<AlertDialog open={romToRemove !== null} onOpenChange={(open) => !open && setRomToRemove(null)}>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Rimuovere {romToRemove?.title}?</AlertDialogTitle>
      <AlertDialogDescription>
        La ROM verrà rimossa dalla libreria. I save state associati rimarranno nel dispositivo.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Annulla</AlertDialogCancel>
      <AlertDialogAction className="bg-destructive text-destructive-foreground hover:bg-destructive/90" onClick={confirmRemove}>
        Rimuovi
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

**Rimuovere:**
- Handler `onKeyDown` manuale per Esc
- `useEffect` per il focus trap su `RemoveRomConfirmDialog`
- CSS `.sb-dialog-backdrop`, `.sb-dialog` da `app-extra.css` (solo se TSK-153 ha già rimosso `ConfirmGameChangeDialog`, altrimenti rimuovere solo le classi non condivise — coordinare con TSK-153)
