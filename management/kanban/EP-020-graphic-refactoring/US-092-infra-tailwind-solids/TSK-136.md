# TSK-136 — npm install Tailwind + config files

## Esecuzione

Eseguire da `packages/app/`:

```bash
npm install -D tailwindcss postcss autoprefixer tailwindcss-animate
```

Poi creare i seguenti file:

### `packages/app/tailwind.config.cjs`

```js
/** @type {import('tailwindcss').Config} */
module.exports = {
  presets: [require("@soli92/solids/tailwind-preset")],
  content: ["./src/**/*.{ts,tsx}", "./index.html"],
};
```

### `packages/app/postcss.config.cjs`

```js
module.exports = {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
};
```

### `packages/app/src/styles/tailwind.css`

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## Verifica

```bash
npm run build   # deve passare senza errori Tailwind
npm run test    # 662/662 verdi
```
