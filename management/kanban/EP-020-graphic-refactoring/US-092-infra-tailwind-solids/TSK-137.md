# TSK-137 — components.json + path alias + utils.ts

## Context

Scaffaldare la configurazione shadcn/ui per `packages/app` in modo che i componenti installati via shadcn CLI in TSK-138 risolvano correttamente gli import `@/components/ui/*` e `@/lib/utils`.

## Deliverable

### `packages/app/components.json`

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.cjs",
    "css": "src/styles/tailwind.css",
    "baseColor": "blue",
    "cssVariables": true
  },
  "iconLibrary": "lucide",
  "aliases": {
    "components": "@/components",
    "ui": "@/components/ui",
    "utils": "@/lib/utils",
    "hooks": "@/hooks",
    "lib": "@/lib"
  },
  "registries": {
    "@solids": {
      "url": "https://raw.githubusercontent.com/soli92/solids/main/registry/r/{name}.json"
    }
  }
}
```

### `packages/app/tsconfig.json` — aggiungere a `compilerOptions`

```json
"baseUrl": ".",
"paths": {
  "@/*": ["./src/*"]
}
```

### `packages/app/vite.config.ts` — aggiungere a `defineConfig`

```ts
import path from "path";
// ...
resolve: {
  alias: {
    "@": path.resolve(__dirname, "./src"),
  },
},
```

### `packages/app/package.json` — aggiungere a `dependencies`

```json
"clsx": "^2.1.1",
"tailwind-merge": "^2.5.4"
```

### `packages/app/src/lib/utils.ts` — NEW

```ts
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

## Verifica

- `npm run build` passa
- `npm run test` 662/662 verdi
- Import `import { cn } from "@/lib/utils"` risolve correttamente (tsc --noEmit)
