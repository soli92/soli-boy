# TSK-138 — shadcn CLI install + main.tsx CSS imports

## Esecuzione

### Step 1 — Installa i 57 componenti solids via shadcn CLI

Da `packages/app/`:

```bash
npx shadcn@latest add @solids/solids-ui --yes
```

Il flag `--yes` risponde automaticamente `y` a tutte le conferme.

### Step 2 — Aggiorna gli import CSS in `src/main.tsx`

Aggiungere **dopo** `import "@soli92/solids/css/index.css"`:

```ts
import "@soli92/solids/css/shadcn.css";
```

Aggiungere **alla fine** (ultimo import CSS):

```ts
import "./styles/tailwind.css";
```

L'ordine finale degli import CSS in `main.tsx` deve essere:

```ts
import "./styles/solids-theme.css";
import "@soli92/solids/css/index.css";
import "@soli92/solids/css/shadcn.css";    // ← nuovo
import "./styles/app-extra.css";
import "./styles/tailwind.css";             // ← nuovo (ultimo)
```

## Verifica

```bash
ls src/components/ui/ | wc -l   # ≥ 57
npm run build                    # deve passare
npm run test                     # 662/662 verdi
npm run e2e:ci                   # 30/30 verdi
```

Aprire `localhost:5173`: l'app deve apparire identica all'attuale (nessun componente è ancora migrato).
