# US-092 — Infra: Tailwind + Solids Registry + CSS Bridge

## Descrizione

Come sviluppatore, voglio che `packages/app` sia configurato con Tailwind CSS, il bridge `shadcn.css` di `@soli92/solids` e tutti i 57 componenti React installati via shadcn CLI, affinché le storie di Phase 2 possano adottare i componenti solids senza dipendenze non risolte.

## Business Rules

- `packages/app` non deve avere Tailwind attivo prima di questa US: l'installazione è additive-only, non deve rompere l'app esistente
- L'ordine di import CSS in `main.tsx` rispetta la cascade definita in EP-020: `solids-theme.css` → `@soli92/solids/css/index.css` → `@soli92/solids/css/shadcn.css` → `app-extra.css` → `tailwind.css`
- I test esistenti (662 unit + 30 e2e) devono passare dopo ogni step
- Tutti i TSK sono `consumer: agent` — le operazioni npm/npx vengono eseguite via Bash dall'agente

## Acceptance Criteria

- [x] `packages/app/tailwind.config.cjs` esiste e usa `presets: [require("@soli92/solids/tailwind-preset")]`
- [x] `packages/app/postcss.config.cjs` esiste con tailwindcss + autoprefixer
- [x] `packages/app/components.json` esiste con style: new-york, alias `@/components`, registry `@solids`
- [x] `packages/app/src/lib/utils.ts` esiste con `cn()` = clsx + tailwind-merge
- [x] `packages/app/src/components/ui/` contiene ≥57 file .tsx (installati via shadcn CLI)
- [x] `packages/app/src/styles/tailwind.css` importa `@tailwind base/components/utilities`
- [x] `main.tsx` importa `shadcn.css` (dopo `index.css`) e `tailwind.css` (ultimo)
- [x] `tsconfig.json` ha `paths: {"@/*": ["./src/*"]}`; `vite.config.ts` ha `resolve.alias: {"@": ...}`
- [x] `npm run build` passa senza errori
- [x] `npm run test` — 662/662 unit verdi
- [x] `npm run e2e:ci` — 30/30 e2e verdi
- [x] L'app si avvia su `localhost:5173` senza regressioni visive
