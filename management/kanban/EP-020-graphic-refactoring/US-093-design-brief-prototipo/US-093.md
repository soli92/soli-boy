# US-093 — Design brief + prototipo interattivo EP-020

## Descrizione

Come product owner, voglio vedere un prototipo interattivo navigabile della nuova UI di soli-boy — con dual-theme cyberpunk + 90s-party — prodotto dal Design Intelligence Layer della factory, affinché possa valutare la direzione grafica prima che venga scritta una sola riga di codice produzione.

## Business Rules

- Il prototipo è generato via `/prototype EP-020` (EP-035, §27, `fidelity: interactive`)
- Il backend è `react` (figma/penpot non autenticati → cascade a react per questa sessione)
- Il prototipo deve coprire tutte e 4 le tab (Play, Library, Settings, Info) + dialogs + TouchOverlay layout
- Dual-theme switcher: toggle cyberpunk ↔ 90s-party nella UI del prototipo
- Il prototipo è read-only rispetto alla spec sorgente (INV-3) — nessuna modifica a file US/TSK
- Il prototipo non si auto-valuta (INV-4) — passa obbligatoriamente a ux-ui-review (TSK-142)
- Output in `output/prototypes/ep020/`
