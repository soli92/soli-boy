## Scope del prototipo

**Tab Play:**
- Header con logo soli-boy + nav tabs
- Game screen placeholder (`.sb-screen` aspect-ratio 16:10, `bg-[var(--sd-screen-bg)]`)
- HUD con badge fps + platform + slot (solids `Badge`)
- Player controls: Avvia (primary `Button`), Pausa, Fast-forward, Fullscreen (outline `Button`)
- SaveStatePanel laterale (desktop): 3 slot con Load/Save/Delete (`Button`)
- Idle CTA: "Carica una ROM per iniziare" + `FileLoader` drop zone
- TouchOverlay layout mobile: D-pad sinistra, A/B destra, Select/Start center

**Tab Library:**
- Search input + Label
- Platform filter chips (ToggleGroup: tutti, GB, GBC, GBA, NDS, NES)
- Game grid: 3 tile (2 normali + 1 active "In gioco") con `Card + Badge + Button`
- Empty state con `Empty` component
- FAB / CTA "Carica ROM"

**Tab Settings:**
- 6 sezioni `Accordion`: Video, Audio, BIOS, Controlli, Aspetto, Dati
- Sezione Video: Select (scala), Select (filtro), Switch (scanline)
- Sezione Audio: `Slider` (volume) + `Switch` (muto)
- Sezione Aspetto: `RadioGroup` tema (90s-party, dark, cyberpunk)
- Sezione Controlli: tabella keymap con `Kbd` + `Button` remap
- Sezione Dati: `Button` export/import/clear

**Tab Info:**
- `Card` PrivacyNotice
- `Alert` StoreComplianceNotice
- `Card` LegalNotice

**Dialogs:**
- ConfirmGameChangeDialog: `AlertDialog` con "Cambia gioco?" — annulla / conferma
- RemoveRomConfirmDialog: `AlertDialog` con "Rimuovi ROM?" — annulla / rimuovi

**Dual-theme switcher:**
- Floating toggle in header: cyberpunk ↔ 90s-party
- Cambia `document.documentElement.dataset.theme`

## Output

`output/prototypes/ep020/` — file React standalone (Vite/React, usa solids components installati localmente o via CDN Tailwind per self-contained).

## Verifica

- Il prototipo si avvia in browser (dev server o `index.html` standalone)
- Le 4 tab sono cliccabili e mostrano il contenuto corretto
- Il dual-theme switcher cambia visibilmente il tema
- I dialog si aprono cliccando i trigger appropriati
