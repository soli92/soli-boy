# TSK-140 — Art-Director DSL — EP-020 Design Brief

## Context

Attivare la pipeline Design Intelligence Layer (§24, `design_intelligence.enabled: true`) per produrre il DSL art-director che vincola il prototipo e i TSK di Phase 2. Il DSL è il contratto visivo di EP-020: nessun agente FE può ignorarlo (R.D1).

## Deliverable

`wiki/design/ep020-design-brief.md` — contenuto:

### 1. Brand Identity Constraints

**cyberpunk (tema showcase primario):**
- Canvas: `#0C0E12` → `--sd-color-bg-canvas` cyberpunk
- Primary: neon cyan `#06b6d4` → `--sd-color-primary-default`
- Accent: magenta elettrico per azioni distruttive/danger
- Radii: sharp — sm=2px, md=4px (contrasto intenzionale con layout organico)
- Font heading: Orbitron; body: Space Grotesk; mono: JetBrains Mono (invariante HUD)
- Shadows: neon glow (cyan box-shadow per elementi interattivi attivi)

**90s-party (tema brand default):**
- Canvas: saturated purple
- Primary: vivid magenta
- Radii: md=12px, lg=16px (arrotondati, "rave")
- Font heading/body: DM Sans / Inter (standard DS)
- Shadows: standard `--sd-shadow-sm/md`

### 2. Component-to-Surface Mapping

Vedere tabella in EP-020.md (Component Mapping Table).

### 3. Token Contract

- `--sd-*` token CSS sono autoritativi — nessun colore hardcoded
- `--sd-color-accent-1..5` preservati per game tile art (non rimpiazzabili da solids)
- `--sd-screen-bg` / `--sd-screen-accent` preservati per viewport emulatore
- `--sd-color-pad-a` / `--sd-color-pad-b` preservati per TouchOverlay
- shadcn variables bridge (`--background`, `--primary`, `--card`, `--border`, `--ring`, ...) leggono da `--sd-*` via `shadcn.css`

### 4. Tipografia

- HUD (fps, core, slot): `font-family: var(--sd-font-mono)` (JetBrains Mono) — invariante gaming
- Headings (section titles, screen titles): `var(--sd-font-heading)` (DM Sans / Orbitron per cyberpunk)
- Body/UI: `var(--sd-font-body)` (Inter / Space Grotesk per cyberpunk)
- Scale: xs per badge/caption, sm per body, md per button labels, lg per section headings

### 5. Principi di Interazione

- Tab navigation: Radix Tabs (keyboard Arrow/Home/End) — mantiene ARIA tablist semantics corrette
- Dialogs: Radix AlertDialog per azioni distruttive — focus trap + Esc + Portal nativo
- Form controls: Radix Switch/Slider/Select — keyboard Space/arrow/Enter nativo
- TouchOverlay: CSS-only positioning (no JS motion), solo visual styling migrato a Tailwind
- Game canvas `.sb-screen`: invariante — posizionamento, aspect-ratio, safe-area non toccati
