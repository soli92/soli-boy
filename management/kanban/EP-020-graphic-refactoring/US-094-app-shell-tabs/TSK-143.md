# TSK-143 — App shell + Tabs navigation migration

## Context

`App.tsx` gestisce l'intera app shell: `<header>` con logo, un `<nav role="tablist">` con 4 `<button role="tab">` (classi `sb-tab-btn`) e 4 `<section role="tabpanel">` (classi `sb-tab-panel`). La keyboard navigation è implementata manualmente con `onKeyDown`. La tab Play usa `hidden` attribute per nascondere il contenuto senza smontarlo.

## Migrazione

**Sostituire:**
- `<nav role="tablist">` + `<button role="tab" className="sb-tab-btn ...">` → solids `<Tabs>` + `<TabsList>` + `<TabsTrigger value="...">` (Radix gestisce internamente i ruoli ARIA e la keyboard navigation)
- `<section role="tabpanel" className="sb-tab-panel ...">` → `<TabsContent value="..." forceMount>` (per la tab Play: `forceMount` + `hidden` via `data-state="inactive"` CSS rule)
- `state.activeTab` + `setActiveTab` → `value` prop su `<Tabs>` (controlled) o state locale

**Rimuovere:**
- Handler `onKeyDown` manuale per Arrow/Home/End (gestito da Radix)
- Classi CSS `.sb-tab-bar`, `.sb-tab-btn`, `.sb-tab-btn--active`, `.sb-tab-panel` da `app-extra.css`

**Mantenere:**
- Layout `<header>` con logo (solo styling → Tailwind)
- Il gate `pendingRom !== null` per `ConfirmGameChangeDialog` (gestito in TSK-153)
- Tutti i componenti figli (Player, Library, Settings, etc.) rimontati invariati

**Tailwind layout app shell:**
```tsx
<div className="flex flex-col min-h-svh max-w-[920px] mx-auto">
  <header className="flex items-center gap-3 px-4 py-3 border-b border-border">
    <img src={logo} className="h-7" alt="soli-boy" />
  </header>
  <Tabs value={activeTab} onValueChange={setActiveTab} className="flex flex-col flex-1">
    <TabsList className="w-full rounded-none border-b border-border">
      <TabsTrigger value="play">Play</TabsTrigger>
      <TabsTrigger value="library">Libreria</TabsTrigger>
      <TabsTrigger value="settings">Impostazioni</TabsTrigger>
      <TabsTrigger value="info">Info</TabsTrigger>
    </TabsList>
    <TabsContent value="play" forceMount className="flex-1 data-[state=inactive]:hidden">
      <Player ... />
    </TabsContent>
    {/* ... altri TabsContent */}
  </Tabs>
</div>
```
