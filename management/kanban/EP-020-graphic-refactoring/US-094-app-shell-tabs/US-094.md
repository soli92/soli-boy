# US-094 — App shell + Tabs navigation migration

## Descrizione

Come developer, voglio migrare l'app shell e la navigazione a 4 tab da HTML raw + classi `sb-tab-*` a solids `Tabs` (Radix UI), affinché l'ARIA tablist, la keyboard navigation e il visual styling siano gestiti nativamente dal componente.

## Acceptance Criteria

- [x] La navigazione a 4 tab usa `Tabs`, `TabsList`, `TabsTrigger`, `TabsContent` di solids
- [x] `role="tablist"`, `role="tab"`, `role="tabpanel"` e `aria-selected` sono corretti (gestiti da Radix)
- [x] Keyboard navigation: ArrowLeft/ArrowRight cicla le tab, Home/End salta a prima/ultima
- [x] Il tab Play è `forceMount` (always-mounted, mai smontato)
- [x] Le classi `.sb-tab-bar`, `.sb-tab-btn`, `.sb-tab-btn--active` sono rimosse da `app-extra.css`
- [x] Visual oracle: 3 temi × 2 viewport (375 + 1280) — screenshot passano
- [x] axe-playwright: 0 finding critical su navigazione tabs
