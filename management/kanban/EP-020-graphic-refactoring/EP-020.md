# EP-020 — Graphic Refactoring & Solids Component Migration

> Migrare l'intera UI di soli-boy da HTML raw + classi CSS hand-written (`sb-*`/`sd-*`) a componenti React tipizzati di `@soli92/solids` (shadcn/ui + Radix UI + Tailwind CSS), preceduta da un prototipo interattivo dual-theme generato via Design Intelligence Layer (EP-035).

## Obiettivo

soli-boy usa attualmente HTML raw + un sistema di classi CSS hand-written (`sb-*`, `sd-*`) costruito sopra i token CSS di `@soli92/solids`. Il DS espone già 57 React components (shadcn/ui pattern, Radix UI, CVA, Tailwind) via registro shadcn CLI, mai utilizzati nell'app. La factory v2.26 introduce il Prototype Generation Layer (EP-035, `/prototype`) e il Design Intelligence Layer (§24).

L'epica:
1. **Prepara l'infrastruttura** — aggiunge Tailwind CSS a `packages/app`, installa i 57 componenti solids via shadcn CLI, cablando il bridge `shadcn.css` nella cascade CSS
2. **Produce un prototipo interattivo dual-theme** — art-director DSL → wireframes → `/prototype EP-020` (cyberpunk + 90s-party, tutte le 4 tab, output `output/prototypes/ep020/`)
3. **Migra per superficie** — ogni componente `sb-*` rimpiazzato da solids component equivalente, con pipeline completa: develop → visual-oracle → a11y → ux-ui-review → code-review
4. **Consolida il CSS** — rimozione progressiva delle classi orfane, mantenendo gli override WCAG AA e le regole positioning game-specific

## Architettura CSS (ordine import finale in `main.tsx`)

```ts
import "./styles/solids-theme.css";          // token app-specific (accent ramps, screen-bg)
import "@soli92/solids/css/index.css";        // --sd-* custom properties + 12 themes
import "@soli92/solids/css/shadcn.css";       // bridge --sd-* → --background/--primary/…
import "./styles/app-extra.css";              // WCAG AA overrides (post-bridge, deve vincere)
import "./styles/tailwind.css";               // @tailwind base/components/utilities (ultimo)
```

## Valore

- **Coerenza design system**: tutti i pattern UI espressi con componenti tipizzati del DS ufficiale
- **Accessibilità automatica**: Radix UI gestisce ARIA roles, keyboard navigation, focus management nativamente (niente più focus trap hand-rolled)
- **Prototipo navigabile**: stakeholder possono vedere la UI rinnovata con dual-theme prima di qualsiasi implementazione
- **Manutenibilità**: 57 componenti riutilizzabili, varianti via CVA, aggiornabili via shadcn registry
