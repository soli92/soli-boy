# TSK-156 — CSS cleanup: rimozione classi orfane

## Procedura

Per ciascuna classe nella lista "rimuovere", eseguire:

```bash
grep -r "className.*CLASSE\|class=\".*CLASSE" packages/app/src --include="*.tsx" --include="*.ts"
```

Se 0 risultati → la classe è orfana → rimuovere dal CSS.

**Classi da verificare e rimuovere (se orfane):**

Da `solids-theme.css`:
- `.sd-flex`, `.sd-items-center`, `.sd-between`, `.sd-center`, `.sd-gap-sm`, `.sd-gap-md`, `.sd-wrap`
- `.sd-card`
- `.sd-badge` (generic, non `.sd-badge.sb-chip`)
- `.sb-btn`, `.sb-btn-primary`, `.sb-icon`, `.sb-full`, `.sb-danger`
- `.sb-search`, `.sb-search i`, `.sb-search input`
- `.sb-chip`, `.sb-chip-on` (entrambe le classi)
- `.sb-grid`, `.sb-tile`, `.sb-game`, `.sb-tt`, `.sb-mt`, `.sb-add`
- `.sb-hud`
- `.sb-secs`, `.sb-sec`, `.sb-lbl`, `.sb-row`, `.sb-sel`, `.sb-range`, `.sb-tog`, `.knob`
- `.sb-badge-success`, `.sb-note`

Da `app-extra.css`:
- `.sb-tab-bar`, `.sb-tab-btn`, `.sb-tab-btn--active`, `.sb-tab-panel`
- `.sb-dialog-backdrop`, `.sb-dialog`
- `.sb-accordion-wrap`, chevron `summary::after` CSS
- `.sb-loader`, `.sb-dropzone`
- `[data-theme="90s-party"] .sb-chip-on` (solo se `.sb-chip-on` è stato rimosso)
- `[data-theme="cyberpunk"] .sb-chip-on` (idem)

**Classi da MANTENERE (non toccare):**
- `:root` token block in `solids-theme.css` — accent ramps `--sd-color-accent-*`, pad colors `--sd-color-pad-*`, `--sd-screen-bg`, `--sd-screen-accent`
- `.sb-art`, `.a-1`, `.a-2`, `.a-3`, `.a-4`, `.a-5` (game tile color ramps — usate in TSK-146)
- `[data-theme="dark"]` e `[data-theme="cyberpunk"]` WCAG AA overrides su `--sd-color-*` in `app-extra.css`
- `.sb-screen`, `.sb-canvas-status` — game viewport
- `.sb-touch-overlay`, `.sb-dpad`, `.sb-ab`, `.dp`, `.dp-up/down/left/right/center`, `.ab`, `.ab-*` — positioning (il visual styling è in Tailwind da TSK-155, il positioning resta qui)
- `@media (orientation: landscape)` rules
- `env(safe-area-inset-*)` rules
