# US-100 — CSS cleanup + full regression suite

## Descrizione

Come developer, voglio rimuovere tutte le classi CSS orfane (`sb-*`/`sd-*` utility) da `solids-theme.css` e `app-extra.css` dopo grep-confirm dell'intero `src/`, e verificare che l'intera test suite (unit + e2e + visual oracle) passi senza regressioni.

## Acceptance Criteria

- [ ] Nessuna classe `sb-btn*`, `sb-tog`, `sb-sel`, `sb-range`, `sb-search`, `sb-chip`, `sb-sec`, `sb-lbl`, `sb-row`, `sb-key`, `sb-note`, `sb-grid`, `sb-tile`, `sd-card`, `sd-flex`, `sb-dialog-backdrop` è ancora referenziata in `src/` dopo la rimozione
- [ ] Le classi WCAG AA override (`[data-theme="dark"]`, `[data-theme="90s-party"]`, `[data-theme="cyberpunk"]`) sono intatte
- [ ] Le classi game-specific invarianti (`.sb-screen`, `.sb-canvas-status`, `.sb-touch-overlay`, positioning rules, safe-area) sono intatte
- [ ] `npm run test` ≥ 662/662 unit verdi
- [ ] `npm run e2e:ci` 30/30 verdi
- [ ] Visual oracle: 3 temi × 2 viewport × 4 tab = 24 screenshot passano
- [ ] axe-playwright: 0 critical su tutti i temi
- [ ] `npm run build` produce dist valido (nessun Tailwind purge false-negative)
