# TSK-132 — Test integrazione/e2e: flusso RTC completo (set, persist, save-state, sync-to-device)

## Context

Task di chiusura della wave EP-019: verifica end-to-end (con StubEngine + bridge mock) che
il flusso completo dell'RTC funzioni — impostazione data/ora dal Settings, persistenza fra
sessioni, inclusione nel save state con compat all'indietro, e allineamento all'orologio del
dispositivo. Il test e2e usa `StubEngine` (deterministico, senza ROM reale richiesta) con
un `StubRtcBridge` mock che permette verifica comportamentale del dominio (conforme ADR-009 §4).

**Nota bridge concreti Sprint 16:** i test con engine reale (WasmBoyRtcBridge su Gambatte
+ ROM Pokémon GBC; MgbaRtcBridge su mGBA + ROM Pokémon GBA) sono marcati
`test.skip('bridge concreto Sprint 16 — ADR-009 §4 follow-up')` e verranno abilitati
quando i bridge `WasmBoyRtcBridge` / `MgbaRtcBridge` saranno implementati.

## Test Cases

### Scenari unit (ricopertura integrazione)

1. **Visibilità condizionale Settings** — `RtcSection` non presente su piattaforma senza RTC (GBA), presente su GBC.
2. **Validazione form** — input mese=13 → pulsante "Imposta" disabilitato; input valido → abilitato.
3. **Set RTC** — click "Imposta" con valori noti → `bridge.setRtcState` chiamato; messaggio success visibile.
4. **Sync to device** — click "Usa ora del dispositivo" → campi aggiornati, `setRtcState` non chiamato automaticamente.

### Scenari integrazione dominio

5. **Persist on stop** — `GameSession.stop()` con bridge mock → `putRtcState` chiamato in IDB (verificato su adapter test).
6. **Restore on start** — `GameSession` load con `getRtcState` che ritorna stato mock → `setRtcState` chiamato con quel valore.
7. **Persist on stop best-effort** — `putRtcState` rigetta → nessun throw, `console.warn`, gioco stoppato normalmente.

### Scenari e2e Playwright (StubEngine + bridge mock)

8. **e2e: set RTC visibile** — aprire Settings con GBC stub → sezione "Data e ora" presente; aprire con GBA stub → sezione assente.
9. **e2e: save state include RTC** — creare save state con RTC mock a valore A; cambiare RTC a valore B; ripristinare save state → bridge riceve valore A (compat forward).
10. **e2e: save state pregresso** — ripristinare save state senza campo `rtcState` → restore completa, nessun errore, `setRtcState` non chiamato.
11. **e2e: sync to device** — click "Usa ora del dispositivo" → campi mostrano ora corrente (mock Date); nessuna richiesta di rete intercettata (Playwright `page.route` assert).

### Scenari skip bridge concreto Sprint 16 (marcati `test.skip`)

12. **[SKIP — WasmBoyRtcBridge Sprint 16]** e2e con WasmBoyEngine reale + ROM GBC con MBC3 → sezione RTC visibile e `getRtcState` non null.
13. **[SKIP — MgbaRtcBridge Sprint 16]** e2e con mGBA + ROM GBA con S-3511A → sezione RTC visibile; ROM GBA senza RTC → sezione non visibile.
