# TSK-028 — MgbaEngine (GBA) — spike + adapter

## Context

## Technical Specs
- **Spike prima:** validare un pacchetto mGBA wasm con API JS (es. mgba.js / build esistente) — confermare licenza, API (loadROM/play/pause/audio/input), canvas.
- **Adapter:** `MgbaEngine implements EmulatorEngine`; registrato in selectEngine per `mgba`.
- Se nessun pacchetto idoneo → STOP, segnala (gap) e mantieni GBA "non supportato" temporaneo.

## Implementation Steps
1. Spike: identificare/validare la lib mGBA wasm.
2. Adapter + registrazione nel registry.
3. Verifica con ROM GBA homebrew libera (se disponibile).
