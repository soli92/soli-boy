# TSK-025 — WasmBoyEngine (GB/GBC) + engine registry

## Context
Sostituire EmulatorJS (core non caricabile in self-host) con WasmBoy per GB/GBC; introdurre la selezione engine per-piattaforma. [^src: management/kanban/EP-003-esecuzione-e-controlli/US-010-avvio-emulazione/US-010.md §Acceptance Criteria]

## Technical Specs
- **core:** `WasmBoyEngine implements EmulatorEngine` (npm `wasmboy`, ESM) come da [ADR-005](../../../../design_&_architecture/decisions/ADR-005.md): crea un `<canvas>` nel container (TSK-022), `WasmBoy.config` + `loadROM(bytes)` + play/pause/stop, audio, input.
- **registry:** `selectEngine(core)` → WasmBoyEngine (gambatte) | MgbaEngine (mgba, TSK-028) | Stub; arcade → "non supportato" pulito (rinvio, EP-009).
- App usa il registry al posto della selezione EmulatorJsEngine.

## Implementation Steps
1. `npm i wasmboy`; adapter WasmBoyEngine (canvas in container, loadROM da Blob→Uint8Array).
2. `core/engine-registry.ts` con `selectEngine(core)`.
3. Wire in App; StubEngine resta default per test/e2e.

## Definition of Done
- [ ] GB/GBC: una ROM libera (dmg-acid2.gb) avvia ed emula (canvas renderizza) — verifica in TSK-027
- [ ] Unit/e2e (stub) invariati; typecheck OK
- [ ] arcade → messaggio "non ancora supportato" (no crash)
