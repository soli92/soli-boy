# TSK-016 — InputMapping: tastiera + Gamepad API

## Context
Il gioco deve essere controllabile da tastiera e da gamepad. [^src: management/kanban/EP-003-esecuzione-e-controlli/US-012-input-tastiera-gamepad/US-012.md §Acceptance Criteria]

## Technical Specs
- **BE:** servizio `InputMapping` che instrada eventi tastiera e Gamepad API verso il `CoreWrapper` (TSK-007), via `bindInput`.
- Gestione collegamento/scollegamento gamepad in corsa senza interrompere la sessione.

## Implementation Steps
1. Catturare gli input tastiera e Gamepad API.
2. Mapparli sui comandi del core via `bindInput`.
3. Gestire connect/disconnect del gamepad a runtime.

## Definition of Done
- [ ] Input tastiera controlla il gioco
- [ ] Gamepad riconosciuto controlla il gioco; connect/disconnect gestiti
- [ ] Code review approvata

## Dependencies
- TSK-007 — input bridge del core
