# TSK-018 — CoreWrapper: fast-forward + rewind (capability)

## Context
Fornire fast-forward e, dove supportato dal core, rewind. [^src: management/kanban/EP-003-esecuzione-e-controlli/US-014-fast-forward-rewind/US-014.md §Acceptance Criteria]

## Technical Specs
- **BE/core:** `CoreWrapper.setSpeed` (fast-forward on/off; rewind se supportato) come da [core-wrapper](../../../../design_&_architecture/api_specs/core-wrapper.md), esponendo una capability per il rewind.
- Se il core non supporta il rewind, il comando è disabilitato lato UI.

## Implementation Steps
1. Implementare il fast-forward.
2. Esporre la capability di rewind e implementarlo dove supportato.

## Definition of Done
- [ ] Fast-forward attivabile in esecuzione
- [ ] Rewind disponibile solo dove il core lo supporta (capability esposta)
- [ ] Code review approvata
