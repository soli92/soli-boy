# TSK-080 — Scan a11y + UX/UI retroattivo: griglia DS, ricerca/filtro, copertina (EP-002)

## Context

Remediation v2.18: i componenti Library avanzati (integrazione design system reale @soli92/solids,
ricerca + filtro piattaforma, anteprima copertina) sono in produzione (`done`) ma privi di
`a11y_status`/`ux_ui_status`. Questo task esegue la verifica retroattiva.
[^src: management/kanban/EP-012-remediation-a11y-ux-ui/US-045-a11y-ux-ui-libreria-avanzata/US-045.md §Acceptance Criteria]

**TSK sorgente coperti:**
- TSK-040 — Integrazione @soli92/solids reale (cross-cutting UI, griglia Library con token DS)
- TSK-038 — Ricerca + filtro piattaforma (Library): campo search + chip radiogroup
- TSK-039 — Copertina gioco (upload/display): area upload copertina + immagine nella card

**Ordering (verifiche retroattive — nessun nuovo develop):**
`visual-oracle (già eseguito) → /a11y → /ux-ui-review → valorizza frontmatter TSK sorgente`

## Technical Specs

### Scan a11y

Eseguire `/a11y TSK-080` coprendo:
- Griglia Library post-@soli92/solids: token colore, contrasto temi 90s-party/dark.
- Campo search: `<input type="search">`, label, `role=radiogroup`/`role=radio` + `aria-checked`.
- Stato vuoto Library: `role=status` leggibile da screen-reader.
- Upload copertina: input file copertina, preview `<img>` con alt text.

Applicare `run_a11y_scan` con:
- `standard: wcag22aa`
- `viewports: [mobile 375, desktop 1280]`
- `themes: [90s-party, dark]`
- `manual_checks N≥1` (regola di neutralità invariante)

### Review UX/UI

Eseguire `/ux-ui-review TSK-080` applicando la rubrica:
- Nielsen: feedback filtri attivi, prevenzione errori upload, flessibilità (combinabilità search+chip).
- Dimensioni UI: chip visibili su temi scuri, copertina nella card (proporzioni, overflow testo).
- Dimensioni flusso: percorso ricerca → filtra → avvia gioco.

## Implementation Steps

1. Avviare `/a11y` su Library (con e senza risultati, con e senza copertina) in viewport mobile+desktop e temi.
2. Classificare i finding.
3. Avviare `/ux-ui-review` con rubrica completa.
4. Valorizzare `a11y_status` + `ux_ui_status` nei frontmatter di TSK-040, TSK-038, TSK-039.
