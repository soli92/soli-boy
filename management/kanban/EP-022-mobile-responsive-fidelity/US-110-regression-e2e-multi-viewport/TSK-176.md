# TSK-176 — Suite e2e multi-viewport EP-022 (US-110)

## Context

Regression guard finale dell'epica EP-022: suite Playwright strutturale che copre i quattro
viewport (mobile portrait, mobile landscape, tablet, desktop) su tutte e quattro le tab ed
entrambi i temi, proteggendo contro drift futuri del tipo bug US-105 (navbar overlay portrait).
Dipende dalla chiusura di tutti i fix (US-105, US-107, US-108, US-109). [^src: US-110, EP-022]

La suite è **strutturale** (marker DOM, visibilità, cliccabilità) — non pixel-diff rigido —
coerente con la scelta EP-021 (`ep021-visual-fidelity.e2e.ts`). Test rossi = gate umano (R.16
se via CQRL). [^src: wiki/concepts/layout-responsive.md]

**Nota:** il test per portrait (TSK-167 `ep022-portrait-navbar.e2e.ts`) è già esistente e resta
autonomo. La suite TSK-176 fa riferimento alle stesse assertion e le consolida in una matrice
sistematica sui 4 viewport — senza duplicare i test TSK-167, ma richiamandone la logica.

## Technical Specs

**Nuovo file:** `packages/app/e2e/ep022-multi-viewport.e2e.ts`

**Matrice di copertura:**

| Viewport | Width×Height | Breakpoint | Tab bar location |
|---|---|---|---|
| Mobile portrait | 390×844 | ≤639px | 2a riga header (colonnare, ThemeSwitcher in Settings) |
| Mobile landscape | 844×390 | ≥640px (width), orientamento landscape | header a riga |
| Tablet portrait | 768×1024 | `md:` 768px | header a riga |
| Desktop | 1280×800 | `lg:` 1024px+ | header a riga + ThemeSwitcher nell'header |

**Struttura del test (`test.describe.each` per viewport):**

```ts
const VIEWPORTS = [
  { name: 'mobile-portrait', width: 390, height: 844 },
  { name: 'mobile-landscape', width: 844, height: 390 },
  { name: 'tablet', width: 768, height: 1024 },
  { name: 'desktop', width: 1280, height: 800 },
];

const TABS = [
  { label: 'Play', testId: 'panel-play' },
  { label: 'Libreria', testId: 'panel-library' },
  { label: 'Impostazioni', testId: 'panel-settings' },
  { label: 'Info & Privacy', testId: 'panel-info' },
];

const THEMES = ['cyberpunk', '90s-party']; // subset rappresentativo (entrambi per portrait)
```

**Assertion per ogni viewport × tab:**

1. **TabList visibile:**
   ```ts
   await expect(page.getByRole('tablist', { name: 'Sezioni app' })).toBeVisible();
   ```

2. **Tutti i 4 tab visibili e raggiungibili:**
   ```ts
   for (const tab of TABS) {
     await expect(page.getByRole('tab', { name: tab.label })).toBeVisible();
   }
   ```

3. **Cliccabilità del tab Play** (assertion anti-regressione US-105):
   ```ts
   await page.getByRole('tab', { name: 'Libreria' }).click();
   await page.getByRole('tab', { name: 'Play' }).click();
   await expect(page.getByTestId('panel-play')).toHaveAttribute('data-state', 'active');
   ```

4. **Marker DOM EP-021 stabili** (tutti i viewport):
   ```ts
   await expect(page.locator('.proto-root')).toBeAttached();
   // theme-switcher: nell'header (desktop/tablet/landscape) o in Settings (portrait)
   ```

5. **Non-sovrapposizione logo/tablist** (bounding box):
   ```ts
   const logoBox = await page.locator('.sb-title--logo').boundingBox();
   const tablistBox = await page.getByRole('tablist').boundingBox();
   expect(tablistBox!.y).toBeGreaterThanOrEqual(logoBox!.y + logoBox!.height - 4);
   // Tolleranza 4px per arrotondamenti
   ```

6. **ThemeSwitcher corretto per viewport** (assertion TSK-166):
   ```ts
   if (viewport.width <= 639) {
     // Mobile portrait: ThemeSwitcher assente dall'header
     await expect(page.locator('header .theme-switcher')).not.toBeVisible();
   } else {
     // Tablet/desktop/landscape: ThemeSwitcher presente nell'header
     await expect(page.locator('header .theme-switcher')).toBeVisible();
   }
   ```

**Copertura temi:** entrambi i temi (cyberpunk + 90s-party) obbligatori per portrait (US-105).
Per tablet/desktop: cyberpunk obbligatorio, 90s-party documentato come "covered by TSK-175".
