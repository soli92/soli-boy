# TSK-167 — e2e Playwright portrait navbar (US-105) — P0 bloccante

## Context

Chiusura della US-105 con un test e2e deterministico che asserisce la correttezza del fix
introdotto da TSK-166 (ThemeSwitcher rimosso dall'header mobile + aggiunto in Settings). Il
test è **marker DOM + visibilità/cliccabilità**, non pixel-diff (coerente con la scelta EP-021).
Diventa guardia permanente contro la regressione del bug P0 (navbar overlay su portrait). [^src: US-105, EP-022]

Baseline infrastruttura: `packages/app/playwright.config.ts` e suite esistenti
(`ep021-visual-fidelity.e2e.ts`, `ep019-rtc.e2e.ts`) — il nuovo test si integra nella stessa
infrastruttura senza aggiungere dipendenze.

## Technical Specs

**Nuovo file:** `packages/app/e2e/ep022-portrait-navbar.e2e.ts`

**Viewport di test:** `{ width: 390, height: 844 }` (iPhone 14 Pro portrait, proxy iOS Safari).

**Temi:** cyberpunk e 90s-party (via `page.evaluate(() => document.documentElement.setAttribute('data-theme', '<tema>'))`).

**Assertion strutturali richieste (per ogni tema):**

### 1. Visibilità dei 4 tab
```ts
const tablist = page.getByRole('tablist', { name: 'Sezioni app' });
await expect(tablist).toBeVisible();
await expect(page.getByRole('tab', { name: 'Play' })).toBeVisible();
await expect(page.getByRole('tab', { name: 'Libreria' })).toBeVisible();
await expect(page.getByRole('tab', { name: 'Impostazioni' })).toBeVisible();
await expect(page.getByRole('tab', { name: 'Info & Privacy' })).toBeVisible();
```

### 2. Cliccabilità del tab Play (assertion diretta contro bug US-105)
```ts
// Navigare su un altro tab prima
await page.getByRole('tab', { name: 'Libreria' }).click();
await expect(page.getByTestId('panel-library')).toHaveAttribute('data-state', 'active');
// Poi tornare su Play — era impossibile prima del fix
await page.getByRole('tab', { name: 'Play' })).click();
await expect(page.getByTestId('panel-play')).toHaveAttribute('data-state', 'active');
```

### 3. ThemeSwitcher ASSENTE dall'header su mobile
```ts
// Fix TSK-166: su mobile il ThemeSwitcher è nascosto dall'header (hidden sm:block)
// Verificare che non sia visibile nell'header (nessun elemento .theme-switcher nel header visibile)
const headerSwitcher = page.locator('header .theme-switcher');
await expect(headerSwitcher).not.toBeVisible(); // hidden on mobile
```

### 4. ThemeSwitcher PRESENTE in Settings su mobile
```ts
// Fix TSK-166: il ThemeSwitcher deve essere accessibile da Settings su mobile
await page.getByRole('tab', { name: 'Impostazioni' }).click();
// Espandere l'accordion "Tema" se necessario
const temaAccordion = page.getByRole('button', { name: 'Tema' });
if (await temaAccordion.isVisible()) {
  await temaAccordion.click();
}
// ThemeSwitcher presente in Settings su mobile
await expect(page.locator('.sb-app-main .theme-switcher')).toBeVisible();
```

### 5. Non-sovrapposizione logo/navbar (bounding box assertion)
```ts
const logoBox = await page.locator('.sb-title--logo').boundingBox();
const tablistBox = await tablist.boundingBox();
// La navbar deve essere SOTTO il logo (top della tablist ≥ bottom del logo)
expect(tablistBox!.y).toBeGreaterThanOrEqual(logoBox!.y + logoBox!.height - 2);
```
