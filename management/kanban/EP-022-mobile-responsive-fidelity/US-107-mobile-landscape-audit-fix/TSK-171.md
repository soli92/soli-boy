# TSK-171 — Visual oracle mobile landscape (US-107)

## Context

Verifica visiva post-fix del layout mobile landscape (~844×390) su entrambi i temi (cyberpunk,
90s-party). Produce gli screenshot di riferimento richiesti dal DoD di US-107. Dipende da
TSK-170 (fix landscape applicato). [^src: US-107, EP-022]

## Technical Specs

**Viewport:** `{ width: 844, height: 390 }` (landscape mobile, iPhone 14 Pro landscape proxy).

**Temi:** cyberpunk, 90s-party.

**Tab da coprire:** Play (con Player inattivo + TouchOverlay landscape se visibile), Library,
Settings, Info.

**Output:** screenshot in `code_quality/reports/EP-022-mobile-landscape/` con naming
`<tab>-<tema>.png` (es. `play-cyberpunk.png`, `library-90s-party.png`, ecc.).

**Assertion strutturali aggiuntive (oltre agli screenshot):**
- Tab bar visibile e non sovrapposta al Player/TouchOverlay in landscape.
- `.sb-screen` presenza nel DOM e correttamente sized (nessun collasso a 0px height).
- Nessun horizontal overflow (verifica `document.documentElement.scrollWidth <= viewport.width`).

**Modalità di esecuzione:**
- Usare il visual-oracle headless (`/visual-oracle`) o uno script Playwright dedicato in
  `packages/app/e2e/` (file temporaneo di audit, non di regression — dovrà essere incluso
  nella suite TSK-176 se le assertion sono utili come regression guard).

## Implementation Steps

1. Lanciare l'app in `npm run preview` (porta `:4173`).
2. Per ogni combinazione tab×tema su viewport 844×390:
   a. Navigare alla tab.
   b. Applicare `data-theme`.
   c. Screenshot full-page.
3. Verificare assenza di horizontal overflow per ogni screenshot.
4. Salvare screenshot in `code_quality/reports/EP-022-mobile-landscape/`.
5. Riportare nel commit: "n delta risolti, landscape layout verde".
