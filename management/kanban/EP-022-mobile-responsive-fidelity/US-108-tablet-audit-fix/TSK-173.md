# TSK-173 — Visual oracle tablet (US-108)

## Context

Verifica visiva post-fix del layout tablet (~768px) su entrambi i temi. Produce gli screenshot
di riferimento richiesti dal DoD di US-108. Dipende da TSK-172 (fix tablet applicato). [^src: US-108, EP-022]

## Technical Specs

**Viewport:** `{ width: 768, height: 1024 }` (tablet portrait) + `{ width: 1024, height: 768 }`
(tablet landscape — verifica secondaria).

**Temi:** cyberpunk, 90s-party.

**Tab da coprire:** Play, Library (verifica 3 colonne), Settings (verifica 2 colonne), Info.

**Output:** screenshot in `code_quality/reports/EP-022-tablet/` con naming `<tab>-<tema>-<orientation>.png`.

**Assertion strutturali specifiche:**
- Library: verifica che la griglia abbia 3 colonne (`grid-cols-3`) su 768px portrait.
  ```ts
  const gridEl = page.locator('[data-testid="panel-library"] .grid');
  // computed style deve avere grid-template-columns con 3 colonne
  const cols = await gridEl.evaluate(el =>
    getComputedStyle(el).gridTemplateColumns.split(' ').length
  );
  expect(cols).toBe(3);
  ```
- Settings: verifica che il wrapper delle sezioni abbia 2 colonne su tablet.
- Navbar: `tablist` visibile e non sovrapposta al logo (bounding box check).

## Implementation Steps

1. Lanciare `npm run preview`.
2. Per ogni combinazione tab×tema×orientation su viewport tablet:
   a. Screenshot full-page.
   b. Assertion strutturali per Library e Settings.
3. Salvare in `code_quality/reports/EP-022-tablet/`.
