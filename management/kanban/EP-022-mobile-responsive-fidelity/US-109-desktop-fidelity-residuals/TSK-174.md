# TSK-174 — Fix delta desktop residui post EP-021 (US-109)

## Context

Fix dei delta classificati "blocker" o "major" per il viewport **desktop (~1280px)** identificati
dall'audit US-104 (TSK-165). EP-021 (US-101/102/103) ha allineato shell, Info tab e layout
Player desktop, ma il product owner ha segnalato delta residui rispetto al prototipo EP-020.
US-109 chiude questi residui. [^src: US-109, EP-022]

Riferimenti vincolanti:
- `wiki/concepts/layout-responsive.md` §Adattamenti per sezione — layout desktop attesi:
  - Library: **5 colonne**. [^src: wiki/concepts/layout-responsive.md]
  - Player: layout orizzontale 16:10 con **pannello laterale save state** e input tastiera/gamepad,
    **senza controlli touch**. [^src: wiki/entities/schermata-player.md §Adattamento per dispositivo]
  - Settings: sezioni in **3 colonne**; sezione "Dati" full-width. [^src: wiki/concepts/layout-responsive.md]
- Design brief autoritativo: `wiki/design/ep020-design-brief.md` §6 (R.D1 — no bypass, prototipo
  `output/prototypes/ep020/` è il riferimento).
- Tipografia: `wiki/design/ep020-design-brief.md` §4 (Orbitron/Space Grotesk cyberpunk, DM Sans/Inter
  90s-party; JetBrains Mono invariante HUD).

**Marker DOM stabiliti in EP-021 da preservare:** `proto-root`, `theme-switcher`,
`sb-privacy-section`, `sb-legal-card` — la suite e2e `ep021-visual-fidelity.e2e.ts` resta verde.

## Technical Specs

**File candidate per il fix:**

1. `packages/app/src/components/Library/Library.tsx` — griglia GameTile.
   Target: `lg:grid-cols-5` (su desktop ≥1280px). Verificare presenza del breakpoint `lg:`.
   Attuale stato post EP-020 TSK-146: verificare se è già `grid-cols-2 md:grid-cols-3 lg:grid-cols-5`
   o se manca il breakpoint desktop.

2. `packages/app/src/components/Settings/Settings.tsx` — sezioni Accordion.
   Target: 3 colonne su desktop (`lg:grid-cols-3`). Verificare coordinamento con TSK-172
   (tablet a 2 colonne): la struttura grid dovrebbe essere
   `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` con sezione "Dati" in `col-span-full`.

3. `packages/app/src/styles/app-extra.css` — `.sb-play-row` (righe 154–165) + `.save-panel-desktop`
   (righe 176–185). Il pannello laterale save state è già implementato via `.sb-play-row` con
   `@media (min-width: 768px)`. Verificare se il breakpoint è corretto o se va allineato a
   `min-width: 1024px` (coordinare con TSK-170/172). Verificare che `.save-panel-desktop`
   abbia `width: 14rem` su desktop (riga 182).

4. `packages/app/src/components/Player/Player.tsx` — TouchOverlay su desktop. Il componente
   deve nascondere il TouchOverlay su desktop (nessun controllo touch in viewport desktop).
   Verificare che la condizione di visibilità dell'overlay sia già corretta
   (potrebbe dipendere da `isMobile` / media query nel componente).

**Invarianti inviolabili:**
- `proto-root`, `theme-switcher`, `sb-privacy-section`, `sb-legal-card` marker DOM stabili.
- `.sb-screen` aspect-ratio invariante (no modifica).
- Nessun override `--sd-*` senza ADR.
- Tipografia conforme al design brief §4.
- Suite `ep021-visual-fidelity.e2e.ts` verde (regression guard EP-021).

## Implementation Steps

1. Leggere il report `code_quality/reports/EP-022-fidelity-audit.md` (TSK-165) — sezione
   "Desktop" — per la lista definitiva dei delta blocker/major.
2. Per ogni delta blocker/major:
   a. Identificare il componente / file CSS responsabile.
   b. Applicare il fix con il breakpoint Tailwind corretto (`lg: 1024px` o `xl: 1280px`).
3. Library: aggiungere/confermare `lg:grid-cols-5` in `Library.tsx`.
4. Settings: aggiungere/confermare `lg:grid-cols-3` e `col-span-full` per sezione "Dati".
5. `.sb-play-row` / sidebar: confermare il breakpoint e allinearlo con le decisioni di TSK-170/172.
6. Verificare che `ep021-visual-fidelity.e2e.ts` resti verde (nessuna modifica ai marker DOM).
7. `npm run build` verde.
