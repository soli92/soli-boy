# TSK-175 — Visual oracle desktop + marker EP-021 (US-109)

## Context

Verifica visiva post-fix del layout desktop (~1280px) su entrambi i temi e conferma che i
marker DOM stabiliti in EP-021 restino stabili (regression guard). Dipende da TSK-174
(fix desktop applicato). [^src: US-109, EP-022]

## Technical Specs

**Viewport:** `{ width: 1280, height: 800 }` (desktop standard).

**Temi:** cyberpunk, 90s-party.

**Tab da coprire:** Play, Library (verifica 5 colonne), Settings (verifica 3 colonne), Info.

**Output:** screenshot in `code_quality/reports/EP-022-desktop/` con naming `<tab>-<tema>.png`.

**Assertion strutturali specifiche:**

1. **Marker DOM EP-021 stabili:**
   ```ts
   await expect(page.locator('[data-testid="proto-root"], .proto-root')).toBeVisible();
   await expect(page.locator('[data-marker="theme-switcher"], .theme-switcher')).toBeVisible();
   await expect(page.locator('[data-testid="sb-privacy-section"], [data-sb-privacy-section]')).toBeAttached();
   await expect(page.locator('[data-testid="sb-legal-card"], [data-sb-legal-card]')).toBeAttached();
   // Nota: verificare i selettori esatti dai marker introdotti in EP-021 (US-101/102)
   ```

2. **Library griglia 5 colonne su desktop:**
   ```ts
   await page.getByRole('tab', { name: 'Libreria' }).click();
   const gridEl = page.locator('[data-testid="panel-library"] .grid');
   const cols = await gridEl.evaluate(el =>
     getComputedStyle(el).gridTemplateColumns.split(' ').length
   );
   expect(cols).toBe(5);
   ```

3. **Suite EP-021 verde:** eseguire `ep021-visual-fidelity.e2e.ts` in sequenza per confermare.

4. **ThemeSwitcher visibile nell'header su desktop:**
   ```ts
   // Su desktop il ThemeSwitcher è nell'header (fix TSK-166 nasconde solo su mobile)
   const headerSwitcher = page.locator('header .theme-switcher');
   await expect(headerSwitcher).toBeVisible();
   ```

## Implementation Steps

1. Lanciare `npm run preview`.
2. Per ogni tab×tema su viewport 1280×800: screenshot + assertion strutturali.
3. Eseguire `ep021-visual-fidelity.e2e.ts` per confermare regression guard.
4. Salvare screenshot in `code_quality/reports/EP-022-desktop/`.
