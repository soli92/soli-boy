# TSK-113 — Footer cleanup: rimuovi LegalNotice da App.tsx footer

## Context

**UX-003:** `<LegalNotice>` appare sia nella tab "Info & Privacy" (`App.tsx:431-432`)
sia nel footer (`App.tsx:436-438`).
(`[^src5: packages/app/src/App.tsx]`).

La duplicazione è ridondante e occupa spazio prezioso su mobile. `<LegalNotice>` (testo
lungo sulle ROM protette) appartiene alla tab Info, non al footer.

Il footer post-fix deve contenere solo informazioni essenziali (copyright, eventuale link).

## Acceptance Criteria

1. Il `<footer>` in `App.tsx` non contiene più `<LegalNotice>`.
   La riga `<LegalNotice />` nel footer è rimossa.
2. `<LegalNotice>` rimane nella tab Info (in `activeTab === "info"`) — non toccata.
3. Nessuna regressione visiva sul layout footer: il footer è semplicemente più compatto.
4. Test visivo (visual-oracle): screenshot mobile 375px — il footer non mostra la
   sezione legale lunga. Tab Info la mostra correttamente.
5. Test e2e esistenti che verificano `<LegalNotice>` passano (verificano dalla tab Info).

## DoD

- [ ] `<LegalNotice />` rimosso dal `<footer>` in App.tsx
- [ ] LegalNotice nella tab Info invariata
- [ ] Visual oracle footer mobile passante
- [ ] `status: done`
