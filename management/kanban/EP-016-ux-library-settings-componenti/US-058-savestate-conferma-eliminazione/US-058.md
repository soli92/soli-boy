# US-058 — SaveStatePanel: conferma prima di eliminare save state slot

**Come** giocatore che gestisce i miei save state  
**voglio** che l'eliminazione di uno slot save state mi chieda conferma  
**in modo da** non perdere progressi di gioco a causa di un tap accidentale.

## Contesto

Finding `major` UX:

- **UX-023** — Nel SaveStatePanel del Player, il pulsante "Elimina" su uno slot
  rimuove il save state immediatamente senza dialog di conferma. Un tap
  accidentale (specie su mobile) può cancellare ore di gioco.

## Business Rules

- L'eliminazione di un save state slot deve essere un'azione confermata.
- Il dialog di conferma deve mostrare: nome slot/numero, data creazione del save,
  e i pulsanti "Annulla"/"Elimina" con "Annulla" default focus.
- L'azione è distruttiva e non recuperabile: la conferma è obbligatoria, non
  disabilitabile come preferenza.

## Acceptance Criteria

1. Click su "Elimina" su uno slot occupato del SaveStatePanel apre un dialog
   modale con titolo "Eliminare save state?" e testo che include il numero/nome
   dello slot e la data del save.
2. Il dialog ha pulsanti "Annulla" (focus iniziale) e "Elimina" (color destruttivo
   coerente con il design system, es. `sb-danger`).
3. Esc o tap fuori dal dialog = Annulla. Enter sul pulsante "Elimina" focused =
   conferma.
4. La conferma invoca l'azione di delete esistente (`saveService.deleteSaveState`
   o equivalente). In caso di errore mostra `role="alert"` con messaggio.
5. Click su "Elimina" su uno slot vuoto (`occupied === false`) non apre dialog
   (no-op).
6. Test funzionale: scenario "click Elimina → Annulla" → save state ancora
   presente; scenario "click Elimina → conferma" → save state rimosso.
