# TSK-107 — Library GameTile: indicatore visivo ROM corrente

## Context

**UX-012:** Nella Library grid, quando un gioco è in esecuzione, nessun indicatore
visivo lo segnala. L'utente deve passare alla tab Play per scoprire quale gioco sta giocando.

`Library.tsx` (`[^src5: packages/app/src/components/Library/Library.tsx]`) espone
`GameTile` che riceve `rom: RomMeta`. Per mostrare l'indicatore, la tile deve
ricevere una prop `isActive?: boolean` (dalla Library), e la Library deve ricevere
da `App.tsx` l'ID della ROM correntemente in esecuzione (`currentRomId`).

`App.tsx` ha già `selected: RomRecord | null` (riga 77). Basta propagare `selected?.id`
alla Library come prop opzionale `activeRomId?: string`.

## Acceptance Criteria

1. `Library` riceve la prop opzionale `activeRomId?: string` (passata da App.tsx con
   `selected?.id`).
2. `GameTile` riceve `isActive: boolean` e, quando true, mostra:
   - Bordo accent visibile (es. `border: 2px solid var(--sd-color-accent)` o equivalente token)
   - Badge testuale "In gioco" sovrapposto/sotto il titolo
3. Il badge e il bordo sono leggibili su tutti e 3 i temi (90s-party/dark/cyberpunk).
4. Backward compat: `activeRomId` assente → nessuna tile ha il badge (comportamento
   precedente invariato).
5. Test visivo (visual-oracle): screenshot multi-tema con tile attiva → badge + bordo
   visibili su tutti i temi.
6. Test unitario: `GameTile` con `isActive=true` renderizza badge "In gioco".

## DoD

- [ ] Prop `activeRomId` aggiunta a `Library` e propagata come `isActive` a `GameTile`
- [ ] `App.tsx` passa `selected?.id` alla Library
- [ ] Badge + bordo su tutti i temi
- [ ] Test unitario badge + visual oracle
- [ ] `status: done`
