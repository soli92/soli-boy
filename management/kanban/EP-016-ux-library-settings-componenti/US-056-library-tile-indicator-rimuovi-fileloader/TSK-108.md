# TSK-108 — Library GameTile: azione Rimuovi con dialog di conferma

## Context

**UX-017:** La `GameTile` non espone l'azione "Rimuovi dalla libreria".
`storage.removeRom` esiste già nel dominio (TSK-013). L'utente non può pulire la
libreria senza DevTools.

`Library.tsx` (`[^src5: packages/app/src/components/Library/Library.tsx]`) gestisce
lo stato `roms: RomMeta[]`. La rimozione deve aggiornare la lista ottimisticamente e,
in caso di errore, ripristinare e mostrare `error` state.

Se la ROM rimossa è quella in esecuzione (`selected` in App.tsx), il Player deve essere
fermato prima della rimozione: App.tsx deve gestire questa logica tramite una callback
`onRemove?: (romId: string) => void` passata alla Library.

## Acceptance Criteria

1. Ogni `GameTile` espone un controllo "Rimuovi dalla libreria" raggiungibile da keyboard
   (Tab + Enter) e da click/tap. Il controllo è separato visivamente dal pulsante di
   selezione (es. posizionato in basso a destra, etichetta "Rimuovi").
2. Il click su "Rimuovi" apre un dialog di conferma modale:
   - Titolo: "Rimuovere [titolo] dalla libreria?"
   - Pulsanti: "Annulla" (focus iniziale), "Rimuovi" (colore distruttivo `sb-danger`)
   - Se la ROM è quella in esecuzione: avviso aggiuntivo "Stai rimuovendo il gioco
     attualmente in esecuzione. Verrà fermato."
3. La conferma invoca `storage.removeRom(id)` e aggiorna la griglia ottimisticamente.
   In caso di errore, la ROM è ripristinata e `coverError` mostra un messaggio.
4. Se la ROM rimossa è quella in esecuzione, il Player viene fermato (stop) prima
   della rimozione.
5. Esc o click fuori dal dialog = Annulla (nessuna rimozione).
6. Test funzionale: scenario "Rimuovi → Annulla" → ROM ancora presente; "Rimuovi →
   Conferma" → ROM rimossa dalla lista.

## DoD

- [ ] Pulsante "Rimuovi" in `GameTile` accessibile da keyboard
- [ ] Dialog di conferma con avviso per ROM in esecuzione
- [ ] `storage.removeRom` invocato su conferma, aggiornamento ottimistico
- [ ] Player fermato se ROM rimossa è quella in esecuzione
- [ ] Test funzionale rimozione aggiunto
- [ ] `status: done`
