# TSK-109 — De-duplica FileLoader: rimuovi da tab Play idle, mantieni in Library

## Context

**UX-011:** `FileLoader` appare sia nella tab Play (come CTA centrale in stato idle,
`App.tsx:349-367`) sia nella tab Library (`App.tsx:382-388`).
(`[^src5: packages/app/src/App.tsx]`).

La duplicazione crea ambiguità: l'utente non sa dove importare le ROM. Pattern atteso:
importare dalla Library (primario), tab Play idle mostra solo un link alla Library.

L'elemento da rimuovere è la sezione `{!selected && (<div className="sb-play-idle-cta">...)}` in
`App.tsx:349-367`. Dopo la rimozione del FileLoader da lì, la CTA di Play idle deve mostrare solo
"Nessun gioco selezionato" + pulsante "Vai alla Libreria" (il `<button>` a `App.tsx:359-365` esiste già).

## Acceptance Criteria

1. La sezione `sb-play-idle-cta` nella tab Play non contiene più il componente
   `<FileLoader>` completo. Al suo posto mostra solo:
   - Testo "Nessun gioco selezionato"
   - CTA "Vai alla Libreria" (pulsante che cambia tab)
2. Il `<FileLoader>` nella tab Library (`App.tsx:382-388`) resta invariato e funzionante.
3. L'importazione ROM tramite FileLoader in Library funziona come prima.
4. Test visivo (visual-oracle): screenshot tab Play stato idle → nessun FileLoader presente,
   solo il testo e la CTA. Screenshot tab Library → FileLoader presente.
5. Test e2e esistenti che usano FileLoader passano senza modifiche (la Library lo ha ancora).

## DoD

- [ ] `<FileLoader>` rimosso dalla sezione `sb-play-idle-cta` in App.tsx
- [ ] CTA "Vai alla Libreria" presente nel Play idle
- [ ] FileLoader nella Library funzionante
- [ ] Visual oracle Play idle + Library passanti
- [ ] `status: done`
