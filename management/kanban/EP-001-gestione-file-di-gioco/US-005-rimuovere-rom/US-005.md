# US-005 — Rimuovere una ROM dalla libreria

## Descrizione
Come giocatore, voglio rimuovere una ROM dalla libreria, affinché io possa gestire i giochi che conservo localmente.

## Business Rules
- La rimozione elimina la ROM dalla libreria locale.

## UI Reference
[^src: wiki/concepts/libreria-di-gioco.md §Dettaglio]

## Acceptance Criteria
- [ ] È possibile rimuovere una ROM dalla libreria.
- [ ] Dopo la rimozione, la ROM non compare più nella libreria, anche dopo un riavvio.
- [ ] La rimozione richiede una conferma esplicita per evitare cancellazioni accidentali.
