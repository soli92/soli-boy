# TSK-006 — Avviso legale no-copyright

## Context
L'interfaccia deve mostrare un avviso esplicito che l'esecuzione avviene solo su file forniti dall'utente. [^src: management/kanban/EP-001-gestione-file-di-gioco/US-006-avviso-no-copyright/US-006.md §Acceptance Criteria]

## Technical Specs
- **FE:** componente/avviso statico conforme a solids, presente in modo visibile (riferimento: nota in calce a [[schermata-settings]]).
- Nessun accesso a contenuti protetti offerto dall'interfaccia.

## Implementation Steps
1. Realizzare l'avviso legale riusabile (solids).
2. Posizionarlo nei punti previsti (es. Settings, caricamento).

## Definition of Done
- [ ] Avviso visibile e conforme ai token solids
- [ ] Nessun link/accesso a contenuti protetti
- [ ] Code review approvata
