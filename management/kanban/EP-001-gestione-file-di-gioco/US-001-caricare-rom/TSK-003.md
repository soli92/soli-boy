# TSK-003 — FileLoader: selettore file + drag & drop

## Context
Punto d'ingresso utente per caricare una ROM, sia da selettore file sia da trascinamento. [^src: management/kanban/EP-001-gestione-file-di-gioco/US-001-caricare-rom/US-001.md §Acceptance Criteria]

## Technical Specs
- **FE:** componente `FileLoader` (React) su componenti/token solids; selettore file + area drag & drop.
- Riferimento visivo: header con azione "Carica ROM" in [[schermata-library]].
- Al caricamento invoca `StoragePort.addRom` (TSK-002); errore comprensibile su file non valido.

## Implementation Steps
1. Realizzare il componente con selettore file e area drag & drop (solids).
2. Validare il file e gestire l'errore con messaggio comprensibile.
3. Inoltrare il file al dominio per la persistenza.

## Definition of Done
- [ ] Caricamento via picker e via drag & drop funzionanti
- [ ] File non valido → messaggio di errore
- [ ] Componente conforme ai token solids
- [ ] Code review approvata

## Dependencies
- TSK-002 — la porta di persistenza per registrare la ROM
