# US-001 — Caricare una ROM

## Descrizione
Come giocatore, voglio caricare una ROM dal mio dispositivo tramite selezione file o trascinamento, affinché io possa aggiungerla al prodotto ed eseguirla.

## Business Rules
- Il caricamento è disponibile sia tramite selettore file sia tramite drag & drop.
- La ROM caricata è un file fornito dall'utente; il sistema non fornisce contenuti.

## UI Reference
[^src: wiki/concepts/libreria-di-gioco.md §Dettaglio]

## Acceptance Criteria
- [ ] È possibile selezionare un file di gioco tramite un selettore file.
- [ ] È possibile trascinare un file di gioco nell'area dedicata per caricarlo.
- [ ] Dopo il caricamento, la ROM risulta disponibile per l'aggiunta alla libreria.
- [ ] Un file non valido produce un messaggio di errore comprensibile.
