# US-004 — Persistenza locale e ripresentazione nella libreria

## Descrizione
Come giocatore, voglio che le ROM caricate siano memorizzate localmente, affinché le ritrovi nella libreria agli avvii successivi senza ricaricarle.

## Business Rules
- Le ROM caricate sono memorizzate localmente e ripresentate nella libreria agli avvii successivi.
- I dati restano sul dispositivo dell'utente.

## UI Reference
[^src: wiki/concepts/libreria-di-gioco.md §Dettaglio]

## Acceptance Criteria
- [ ] Una ROM caricata è presente nella libreria dopo un riavvio dell'applicazione.
- [ ] La persistenza avviene localmente, senza invio del file a server esterni.
