# TSK-012 — Library: griglia delle ROM persistite

## Context
Le ROM caricate devono essere ripresentate nella libreria agli avvii successivi. [^src: management/kanban/EP-001-gestione-file-di-gioco/US-004-persistenza-libreria/US-004.md §Acceptance Criteria]

## Technical Specs
- **FE:** componente `Library` (React/solids) che mostra le ROM da `StoragePort.listRoms` (TSK-002) in griglia con titolo e piattaforma.
- Riferimento visivo: [[schermata-library]]; griglia responsive in [[layout-responsive]].

## Implementation Steps
1. Recuperare le ROM persistite via `listRoms`.
2. Renderizzare la griglia (titolo + piattaforma) su solids.
3. Selezione di un elemento → avvio del gioco.

## Definition of Done
- [ ] Le ROM persistite compaiono nella griglia dopo reload
- [ ] Selezione avvia il gioco
- [ ] Code review approvata

## Dependencies
- TSK-002 — `listRoms`
