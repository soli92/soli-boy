# US-003 — Caricare il file BIOS

## Descrizione
Come giocatore, voglio caricare il mio file BIOS per le piattaforme che lo richiedono, affinché i relativi giochi funzionino con piena compatibilità.

## Business Rules
- Il BIOS è richiesto da alcune piattaforme (es. Game Boy Advance) per la piena compatibilità.
- Il BIOS è fornito dall'utente; il sistema non lo distribuisce.

## UI Reference
[^src: wiki/concepts/vincoli-legali-rom-bios.md §Dettaglio]

## Acceptance Criteria
- [ ] È possibile caricare un file BIOS per la piattaforma che lo richiede.
- [ ] Il BIOS caricato è associato alla piattaforma corretta e persistito localmente.
- [ ] Avviando un gioco che richiede il BIOS senza averlo caricato, viene mostrato un avviso che ne indica la necessità.
