# TSK-005 — Gestione BIOS (upload + associazione piattaforma)

## Context
Alcune piattaforme (es. GBA) richiedono un BIOS fornito dall'utente per la piena compatibilità. [^src: management/kanban/EP-001-gestione-file-di-gioco/US-003-caricare-bios/US-003.md §Acceptance Criteria]

## Technical Specs
- **BE:** persistenza del BIOS associato alla piattaforma corretta, via `StoragePort` (config/store dedicato).
- Avvio di un gioco che richiede BIOS mancante → segnala la necessità.
- Il BIOS è fornito dall'utente; nessuna distribuzione (vincolo `raw/tech_stack.md`).

## Implementation Steps
1. Persistere il file BIOS associato alla piattaforma.
2. Esporre lo stato "BIOS caricato" per piattaforma.
3. Verificare la presenza del BIOS all'avvio dei giochi che lo richiedono.

## Definition of Done
- [ ] BIOS persistito e associato alla piattaforma
- [ ] Avvio senza BIOS richiesto → avviso
- [ ] Code review approvata

## Dependencies
- TSK-002 — porta di persistenza
