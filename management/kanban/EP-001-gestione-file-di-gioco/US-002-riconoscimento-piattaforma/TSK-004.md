# TSK-004 — PlatformRecognition (estensione + contenuto → piattaforma/core)

## Context
Il sistema deve riconoscere automaticamente la piattaforma del file caricato per selezionare il core corretto. [^src: management/kanban/EP-001-gestione-file-di-gioco/US-002-riconoscimento-piattaforma/US-002.md §Acceptance Criteria]

## Technical Specs
- **BE:** servizio `PlatformRecognition` che da estensione + contenuto deriva `{ platform, core }`.
- Mapping piattaforma→core come da [core-wrapper](../../../../design_&_architecture/api_specs/core-wrapper.md): Gambatte (GB/GBC), mGBA (GBA), FBNeo/MAME (arcade).
- Formato non supportato/ambiguo → esito con avviso esplicito.

## Implementation Steps
1. Definire la tabella di riconoscimento estensione/contenuto → piattaforma.
2. Mappare piattaforma → core.
3. Gestire il caso non supportato/ambiguo.

## Definition of Done
- [ ] Test unitario sul mapping per GB/GBC, GBA, arcade passa (vedi TSK-010)
- [ ] Caso non supportato gestito con avviso
- [ ] Code review approvata
