# US-002 — Riconoscimento automatico della piattaforma

## Descrizione
Come giocatore, voglio che il sistema riconosca automaticamente la piattaforma del gioco caricato, affinché non debba selezionarla manualmente.

## Business Rules
- Il riconoscimento usa l'estensione e il contenuto del file.
- Le piattaforme riconosciute al lancio sono Game Boy/Game Boy Color, Game Boy Advance e arcade.

## UI Reference
[^src: wiki/concepts/piattaforme-e-core-supportati.md §Contesto]

## Acceptance Criteria
- [ ] Caricando un file GB/GBC, GBA o arcade, la piattaforma viene determinata automaticamente.
- [ ] In caso di ambiguità o formato non supportato, viene mostrato un avviso esplicito.
- [ ] La piattaforma riconosciuta è associata in modo persistente al gioco nella libreria.
