# TSK-180 — Gate umano: notarization macOS su release tag `v*` [HUMAN]

## Context

US-112 — prima release desktop macOS firmata e notarizzata. `consumer: human` — richiede Apple Developer Program, Developer ID certificate, e configurazione segreti GitHub. [^src: ADR-007 §Code signing]

## Technical Specs

- Acquisire Developer ID Application certificate
- Configurare segreti repo: `CSC_LINK`, `CSC_KEY_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`
- Eseguire workflow `release-desktop.yml` su tag `v*` di prova
- Verificare: DMG/ZIP si apre senza warning Gatekeeper su macOS pulito
- Documentare esito in `packages/desktop/README.md` (sezione signing)

## DoD

- [ ] Artefatto macOS firmato e notarizzato pubblicato su GitHub Release
- [ ] Gatekeeper accetta l'installer su macOS test
- [ ] Segreti documentati (nomi only, mai valori) in README

## Dependencies

- TSK-179 (config condizionale)
- Apple Developer account — gate umano R.14
