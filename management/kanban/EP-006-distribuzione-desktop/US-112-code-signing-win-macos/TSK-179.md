# TSK-179 — Config electron-builder signing condizionale + doc segreti CI

## Context

US-112 / ADR-007 — abilitare firma codice quando i segreti CI sono presenti, senza rompere il percorso unsigned di US-104. [^src: design_&_architecture/decisions/ADR-007.md §Code signing]

## Technical Specs

- Aggiornare `packages/desktop/electron-builder.yml`:
  - Sezione `mac` con `hardenedRuntime`, `gatekeeperAssess`, `notarize` condizionale
  - Sezione `win` con `sign`/`certificateSubjectName` quando `CSC_*` presenti
  - Documentare fallback unsigned quando segreti assenti
- Estendere `.github/workflows/release-desktop.yml`:
  - Job macOS/Windows con env `CSC_LINK`, `CSC_KEY_PASSWORD`, `APPLE_*` da secrets (skip signing se assenti)
  - Commenti inline su quali secrets attivano quale target
- Aggiornare `packages/desktop/README.md` con tabella segreti e link Apple/Microsoft docs

## DoD

- [ ] CI unsigned resta verde senza segreti (regressione zero su US-104)
- [ ] Config pronta per signing quando owner aggiunge segreti
- [ ] README documenta prerequisiti human per certificati

## Dependencies

- US-104 done (pipeline unsigned baseline)
