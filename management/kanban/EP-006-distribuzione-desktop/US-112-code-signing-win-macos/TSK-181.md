# TSK-181 — Gate umano: code signing Windows su release tag `v*` [HUMAN]

## Context

US-112 — prima release desktop Windows firmata. `consumer: human` — richiede certificato Code Signing OV/EV e segreti `CSC_*`. [^src: ADR-007 §Code signing]

## Technical Specs

- Acquisire certificato Code Signing da CA pubblica (DigiCert/Sectigo/…)
- Configurare segreti repo: `CSC_LINK`, `CSC_KEY_PASSWORD`
- Eseguire workflow `release-desktop.yml` su tag `v*` di prova (runner `windows-latest`)
- Verificare: installer NSIS installabile; documentare comportamento SmartScreen atteso (EV vs OV)
- Documentare esito in `packages/desktop/README.md`

## DoD

- [ ] Artefatto Windows firmato pubblicato su GitHub Release
- [ ] Installer eseguibile su Windows 10/11 test
- [ ] Note SmartScreen documentate se certificato non-EV

## Dependencies

- TSK-179 (config condizionale)
- Certificato Windows Code Signing — gate umano R.14
