# US-112 — Code signing desktop Windows e macOS

## Descrizione

Come maintainer, voglio che la pipeline `release-desktop.yml` produca installer firmati per Windows e macOS quando i certificati sono configurati nei segreti CI, affinché gli utenti non vedano warning Gatekeeper/SmartScreen e l'auto-update (ADR-008) sia affidabile su tutte le piattaforme.

## Business Rules

- Toolchain: `electron-builder` (ADR-007) — firma condizionale su presenza segreti `CSC_LINK`, `CSC_KEY_PASSWORD`
- macOS: Developer ID + notarization (`APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`)
- Windows: certificato OV/EV da CA pubblica
- Senza segreti: build unsigned continua a funzionare (nessuna regressione US-104)
- Gate umano R.14 per acquisizione certificati e configurazione segreti

## Acceptance Criteria

- [ ] `electron-builder.yml` supporta signing condizionale (unsigned fallback)
- [ ] Workflow release documenta segreti richiesti per macOS e Windows
- [ ] Prima build firmata macOS notarizzata eseguita con segreti owner (gate umano)
- [ ] Prima build firmata Windows eseguita con certificato owner (gate umano)
