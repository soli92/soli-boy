# TSK-054 — NativeFsAdapter: implementa StoragePort su filesystem nativo (Electron IPC)

## Context

ADR-002 prescrive un `NativeFsAdapter` che implementi `StoragePort` per il target desktop
(Electron), mappando le stesse collezioni logiche (`roms`, `saveStates`, `sram`, `config`)
su file nel filesystem nativo. La firma contrattuale di `StoragePort` è definita in
`design_&_architecture/api_specs/storage-port.md`. [^src: design_&_architecture/decisions/ADR-002.md §Decisione]

Il dominio è completamente agnostico rispetto all'adapter: `LibraryService`, `GameSession` e
`SaveService` consumano solo `StoragePort`. [^src: management/kanban/EP-006-distribuzione-desktop/US-023-filesystem-nativo/US-023.md §Business Rules]

## Technical Specs

- Implementa l'interfaccia `StoragePort` (src/storage/storage-port.ts).
- Comunica con il processo main Electron via i canali IPC esposti in TSK-053
  (`window.electronAPI.fs.*`).
- Schema di serializzazione file su disco: directory `~/.soli-boy/` (o equivalente
  platform-specific), una sottodirectory per collezione:
  - `roms/` — metadati JSON + blob binario per ogni ROM.
  - `save-states/` — blob binario per slot, indicizzati per `romId`.
  - `sram/` — blob binario per `romId`.
  - `config.json` — chiave/valore (stesse chiavi del `config` store IDB).
- Stesso formato di chiavi logiche dell'IndexedDBAdapter (garantisce compatibilità export).
- Invariante: nessun dato verso server esterni (identica a IndexedDBAdapter). [^src: design_&_architecture/api_specs/storage-port.md §Invarianti]

## Implementation Steps

1. Creare `src/storage/native-fs-adapter.ts` che implementa `StoragePort`.
2. Implementare ogni metodo del contratto (`addRom`, `listRoms`, `removeRom`, `getRom`,
   `putSaveState`, `listSaveStates`, `restoreSaveState`, `putSram`, `getSram`,
   `exportSave`, `importSave`, `getConfig`, `setConfig`) usando le chiamate IPC.
3. Aggiornare `src/storage/index.ts` per selezionare l'adapter a runtime (step successivo,
   TSK-055), ma qui esportare la classe.
4. Unit test con mock del canale IPC (`window.electronAPI`) — coprire i metodi chiave.

## DoD

- [ ] `NativeFsAdapter` implementa tutti i metodi di `StoragePort` senza errori TypeScript.
- [ ] Unit test coprono `addRom`, `listRoms`, `removeRom`, `putSaveState`,
  `restoreSaveState`, `getConfig`/`setConfig`.
- [ ] Nessuna chiamata di rete (invariante privacy).
- [ ] Build typecheck pulito.

## Dependencies

- TSK-053 (definisce i canali IPC consumati).
- TSK-055 (selezione runtime adapter).
