# US-023 — Accesso al filesystem nativo (desktop)

## Descrizione
Come amministratore locale, voglio che l'applicazione desktop acceda al filesystem nativo, affinché possa aprire e salvare file direttamente sul dispositivo.

## Business Rules
- L'applicazione desktop accede al filesystem nativo per aprire e salvare file.

## UI Reference
[^src: wiki/entities/electron.md §Dettaglio]

## Acceptance Criteria
- [ ] Nella versione desktop è possibile aprire ROM e BIOS dal filesystem nativo.
- [ ] Nella versione desktop è possibile salvare ed esportare file sul filesystem nativo.
