# TSK-162 — CI: electron-builder Linux AppImage

## Context

## Technical Specs

- Estendere `.github/workflows/ci.yml` con job `desktop-dist` (o workflow separato `desktop.yml` trigger su push/PR main)
- Steps: checkout → setup Node 24 → `npm ci` in `packages/app` + `packages/desktop` → `npm run build` in desktop (renderer + main) → `npx electron-builder --linux AppImage` (solo Linux in CI)
- Upload artifact `soli-boy-desktop-linux` con retention 7 giorni
- Dipendenze sistema: librerie electron-builder Linux (usare `--publish never` in CI)
