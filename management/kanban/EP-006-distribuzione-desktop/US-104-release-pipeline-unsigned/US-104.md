# US-104 — Prima build Electron distribuibile + pipeline release unsigned

## Descrizione

Come maintainer, voglio generare automaticamente artefatti installabili desktop (almeno Linux AppImage unsigned in CI) e pubblicarli su GitHub Releases al tag `v*`, affinché gli utenti possano installare Soli-boy senza build locale e la release sia ripetibile.

## Business Rules

- Toolchain: `electron-builder` (ADR-007), renderer = `packages/app/dist` (già wired in `packages/desktop`)
- Primo release **unsigned** ammesso (warning Gatekeeper/SmartScreen documentati in README desktop)
- Code signing = gate umano opzionale (segreti CI), non bloccante per Sprint 19
- Target minimo Sprint 19: **Linux AppImage** in CI su `ubuntu-latest`; Win/macOS build documentate per release locale o job futuri

## Acceptance Criteria

- [x] Job CI (o workflow dedicato) esegue `npm run dist` in `packages/desktop` su Linux e produce AppImage in `packages/desktop/release/`
- [x] Workflow GitHub Release su tag `v*` allega artefatti desktop (almeno AppImage) oltre al web dist
- [x] `packages/desktop/README.md` documenta comando release locale e limiti unsigned
- [x] Smoke `npm run smoke` in `packages/desktop` resta verde in CI dopo le modifiche
