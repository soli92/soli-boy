# TSK-056 — Bundling core emulazione offline nella build Electron

## Context

La versione desktop deve avviare ed eseguire giochi senza connessione di rete: i core WASM
(WasmBoy per GB/GBC, mGBA per GBA) devono essere inclusi localmente nell'installazione
desktop. [^src: management/kanban/EP-006-distribuzione-desktop/US-024-core-offline/US-024.md §Business Rules]

L'architettura già usa questi core come ESM (ADR-005 — WasmBoyEngine, MgbaEngine):
su web sono parte del bundle Vite; su desktop devono essere vendorizzati nella distribuzione
Electron. [^src: design_&_architecture/decisions/ADR-005.md §Decisione]

> **ATTENZIONE — GAP APERTO:** il toolchain di packaging Electron NON è specificato in L4.
> Questo task richiede che il lead-architect decida (Electron Forge / electron-builder /
> custom) prima di poter configurare la copia degli asset WASM nel pacchetto distribuibile.
> `consumer: human` — gate umano. Vedi gap `electron-packaging-toolchain` in `wiki/gaps.md`.

## Technical Specs

- I core WasmBoy e mGBA WASM (già come devDependencies: `wasmboy`, `@thenick775/mgba-wasm`)
  producono file `.wasm` nel bundle Vite. Nella build desktop:
  - Configurare il packaging tool per includere la directory `dist/assets/` (output Vite)
    nella build Electron distribuibile.
  - Verificare che `EJS_pathtodata` / percorsi core WASM siano risolti in modo
    same-origin dalla WebView Electron (file `://` oppure server locale).
- Nessun core proprietario o protetto incluso (vincolo legale). [^src: raw/tech_stack.md §Vincoli confermati]

## Implementation Steps

1. (Prerequisito: decisione toolchain packaging dal lead-architect).
2. Configurare il packaging tool per includere `dist/` (output Vite) come risorse renderer.
3. Verificare che i moduli WASM (wasmboy.wasm, mgba.wasm) siano accessibili offline nel
   pacchetto distribuito su Windows, macOS, Linux.
4. Test smoke: avvio di un gioco GB senza connessione di rete nell'app Electron builddata.

## DoD

- [ ] La build Electron distribuibile include i core WASM.
- [ ] L'avvio di un gioco GB offline ha successo (nessuna richiesta di rete per il core).
- [ ] La build è riproducibile su Windows, macOS, Linux.
- [ ] Nessun core/ROM protetto incluso.

## Dependencies

- TSK-053 (Electron main process).
- Decisione toolchain packaging (gate umano, lead-architect).
