# US-025 — Aggiornamento automatico

## Descrizione
Come amministratore locale, voglio che l'applicazione desktop si aggiorni automaticamente, affinché disponga sempre dell'ultima versione senza interventi manuali.

## Business Rules
- L'applicazione supporta l'aggiornamento automatico delle versioni.

## UI Reference
[^src: wiki/entities/electron.md §Dettaglio]

## Acceptance Criteria
- [ ] L'applicazione desktop rileva la disponibilità di una nuova versione.
- [ ] L'aggiornamento può essere applicato senza reinstallazione manuale.
- [ ] L'esito dell'aggiornamento (successo/errore) è comunicato all'utente.
