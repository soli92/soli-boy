# EP-006 — Distribuzione desktop
> Rendere disponibile il prodotto come applicazione desktop nativa, con accesso al filesystem, core offline e aggiornamenti.

## Obiettivo

Il prodotto deve essere distribuibile come applicazione desktop nativa multipiattaforma, con accesso al filesystem nativo, core inclusi localmente per l'uso offline e aggiornamento automatico delle versioni. [^src: wiki/concepts/distribuzione-web-e-desktop.md §Dettaglio]

## Valore di business

Estende il prodotto agli utenti desktop e abilita l'uso offline, ampliando il bacino e i contesti d'uso.

- [US-023](US-023-filesystem-nativo/US-023.md) — Accesso al filesystem nativo (desktop)
- [US-024](US-024-core-offline/US-024.md) — Core inclusi localmente per uso offline
- [US-025](US-025-aggiornamento-automatico/US-025.md) — Aggiornamento automatico
- [US-104](US-104-release-pipeline-unsigned/US-104.md) — Prima build distribuibile + pipeline release unsigned (Sprint 19)
