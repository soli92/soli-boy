# TSK-104 — Visual oracle + test funzionale HUD Player

## Context

Post-implementazione TSK-103, il Player HUD modificato deve essere verificato
tramite visual oracle e functional oracle per confermare:
- Leggibilità dell'HUD nei 3 temi (90s-party, dark, cyberpunk) e 2 viewport (mobile 375px, desktop 1280px)
- Overlay pausa visibile e dimensionata correttamente
- Annunci aria-live verificabili funzionalmente

Dipende da TSK-103 (implementazione HUD).

## Acceptance Criteria

1. Visual oracle eseguito: 6 screenshot (3 temi × 2 viewport) per gli stati idle, running, paused.
   Tutti i 18 screenshot confermano leggibilità dell'HUD e presenza/assenza icona pausa corretta.
2. Functional oracle: sequenza play → pause verifica che `[aria-live]` container contiene
   "In pausa" e che il container pausa overlay è nel DOM (`data-testid="sb-pause-overlay"` o simile).
3. Nessun errore axe (run_a11y_scan) introdotto dal TSK-103: 0 nuove violation.
4. Test snapshot (se presenti): aggiornati per riflettere le nuove stringhe italiane.
